## ① Context：第一轮结果 + 审稿 → 为什么要第二轮

**第一轮做出了什么（已落地、逐字精确）**：

- **核心机理（probe，全量 N=188 × K=16）**：去噪 FM margin 与 automatic-metric reward 差**反相关**——头条稳健量 **Spearman ρ=−0.187（ρ²≈3.5%、CI[−0.335,−0.036]、显著）**；**Pearson −0.411（r²=0.169、CI[−0.556,−0.235]）**并列标注为「杠杆放大的线性系数」（trim top-5%（10 对）后仍 −0.282、LOO 最大单点影响仅 0.038、**非少数点伪影**）。**偏相关裁决 intrinsic**：`corr(FM-margin, reward-gap | guidance, num_steps, speaker)=−0.392（CI[−0.548,−0.209]）`，控住全部生成 knob 后几乎不变（−0.411→−0.392）→ **反相关非生成-grid 产物**。唯一温和混淆 num_steps(NFE) `corr(FM-margin, num_steps-gap)=−0.237` 被偏相关控住；guidance/speaker 各 −0.067(ns)。per-component 换到 reward-对齐方向后**三轴全负**：(−WER) −0.41 / SIM −0.68 / UTMOS −0.60（SIM/UTMOS 比 WER 强）。
- **下游裁决（Table 1，全量 n=100、bootstrap 95% CI）**：base 0.103/0.891/4.309；**open_soar 0.093/0.844/4.408（唯一改善、UTMOS 五臂最佳）**；dpo_weronly 0.115/0.852/4.112（≈base）；**sft 0.545/0.673/3.917（崩坏，反转）**；**dpo_multiobj 0.752/0.365/2.841，n=75 + 25% 生成失败（灾难崩坏）**。崩坏按「往 automatic-reward 选出的自生成 off-manifold winner 拉多狠」**单调加剧**。
- **叙事重定位**：从「DPO 配方」转为**机理性警示研究**——*When Likelihood Disagrees with Quality: A Cautionary Diagnosis of DPO for Continuous-Latent Flow-Matching TTS (dots.tts)*。新论点：**向 automatic-reward 选出的自生成 off-manifold winner 做 self-training 会退化模型，与训练目标无关（SFT 和 DPO 都崩）∝ 拉向 off-manifold 的强度；唯 open_soar（训向真实 on-manifold 目标）改善**。`L_FM` 是**有效似然代理**（open-SOAR 同损失训满分为证），失败在 **preference-likelihood 对齐**（off-manifold winner）= 已知 likelihood-vs-quality / CFG off-manifold gap。

**第一轮审稿判了什么（[`07`](07-审稿意见-第一轮.md)，Major Revision，5 人一致）**：诚信自我修正（n=24→N=188）与 training-free 探针是论文最大资产、可发表；但留下 6 个 CRITICAL（C1 §6.7 自相矛盾+用错相关量 / C2 TBD 当事实 / **C3 N=1 模型外推整类** / C4 headline-shopping / C5 confound=接受零假设 / C6 诊断标签错位）与若干 MAJOR（无人类听测、near-tie 证据权重、建设性仅训练动力学断言、不可证伪、统计地基、EmergentTTS harness 未实装、per-component 分解……）。

**为什么要第二轮（四个目标，逐一对应 X 臂）**：

1. **把核心做硬**——把「机理性警示」从「N=1 模型 + pilot 规模 + 仅自动指标」加固到可证伪、抗混淆、能复现：高-gap 子集存活（X1）、失败率/崩坏归因入表（X2/X3）、settings-matched 复探针（X5）。
2. **配建设性出路**——负面结果须配「那该怎么做」：SFT-target 梯度对照隔离病因（X4）、on-manifold 重配对救 DPO（X6a）、reward-weighted 非似然目标绕开错配（X6b）。
3. **做泛化**——解 C3：架构级（VoxCPM 第二模型复探针，X10）+ 多语种多说话人（VCTK/AISHELL-3，X11）。
4. **补 RQ2/3**——RQ2 流式 Table 2（X8）、RQ3 reward-hacking 在**非错配**框架内干净复现（X7）+ 表现力 EmergentTTS（X9）。
5. **收尾**——人类听测协议备案（X12，暂不可行→记 limitation）、camera-ready 核验（X13）。

## ⑤ 叙事闭环：这套实验如何把论文做得有说服力

把 X1–X13 装回「机理性警示」叙事，每个 CRITICAL/MAJOR 都有一臂兜底，形成**三层证据 + 一条建设性出路 + 两层泛化**的闭环：

1. **核心机理做硬（X1/X3/X5）**——反相关从「全量 N=188 + 偏相关 partial −0.392」再加两道独立佐证：**高-gap 子集存活**（X1，杀 near-tie 质疑）+ **settings-matched 复探针存活**（X5，杀生成-grid 混淆，与偏相关互证 intrinsic）；崩坏的「怎么崩」由 X3 定性（divergence vs graded、LJ002 聚集）。审稿 C1/C4/C5 与「near-tie 证据权重」全部落地。

2. **病因精确归因（X2/X4）**——Table 1 的「sft 也崩」是最强但最危险的论点（caveat 1：与小数据 SFT 不稳混淆）。**X4 的 SFT-target 梯度对照**是决定性一招：四臂只差 target 在奖励轴的位置，若 **winners 崩最惨、groundtruth 改善、random/losers 居中**，就把退化干净归因于「目标 off-manifold」、坐实「**off-manifold self-training 退化与训练目标无关**」这条核心新论点；X2 让失败率入表，杜绝「只看 WER 漏掉 active degradation」。

3. **负面结果配建设性出路（X6a/X6b/X7）**——警示研究不能只说「别这么做」：**X6a** 问「换 on-manifold pair 能否救 DPO」（数据侧最便宜干预）、**X6b** 给出「reward-weighted 非似然目标」这条**仍用 reward 又不踩错配坑**的正路、**X7** 在**非错配**框架内**干净复现 reward-hacking**——把审稿点名的 Contribution-2(方法) vs Contribution-4(hacking 诊断) 冲突解耦：hacking 是 reward 设计问题、非 DPO 错配伪影。

4. **补满 RQ2/3（X8/X9）**——X8 落地流式 Table 2（RQ2，增益是否迁移到流式）、X9 落地 EmergentTTS 表现力（RQ3 另一面：对齐是否以表现力换鲁棒）。两张 TBD 表补齐，C2「TBD 当事实」自然消解。

5. **两层泛化解 C3（X10/X11）**——**X10 VoxCPM 第二模型**把结论从 N=1 升到**架构级**（diffusion-AR 上复现反相关 → 标题可从「dots.tts」升到「continuous-latent flow-matching/diffusion TTS」；不复现则诚实保持收窄）；**X11 多语种多说话人**让 SIM 变可判别、规模 >188、加中文跨语言——直击「单说话人/pilot 规模」两条 MAJOR。

6. **诚实兜底（X12/X13）**——X12 把「无人类听测」转为**明写的 limitation + 备案协议**（未做前只称 automatic-metric reward）；X13 守仓库铁律（verify 全部 arXiv id、守 C6「intrinsic ≠ intrinsic-to-`L_FM`」、删「首次发现」式措辞）。
