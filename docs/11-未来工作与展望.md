## 三、局限（Limitations，§7 主线）

- **似然-质量错配是中心 caveat** —— automatic-metric reward 偏好与 flow likelihood 反相关（settings-matched ρ=−0.216，top-25% −0.533），likelihood-based DPO 是错误工具；disattenuation ρ_dis=−0.221 为保守下界。
- **L_FM 仅启发式似然代理、非忠实 NLL 上界（C2）** —— X14 typicality inconclusive、无决定性独立锚，caveat 始终保留。`docs/06` §1.1/§4.2、ADR-15。
- **作用域诚实封顶 N=2 continuous-latent** —— 非 all-TTS、非 discrete-token、仅 2 模型；机理可能 architecture-specific（dots.tts VAE/flow-head 几何）。ADR-14。
- **n=100 崩溃定向、混淆、非均匀** —— 子项 (ii) graded-vs-divergence、(iii) LJ002 聚集未决；off-manifold-self-training 仍属 cautionary hypothesis。
- **偏好语料极小（~188 对）+ 候选多样性不足** —— `generate()` 无 seed → reward 方差低、reward_accuracy~0.5。
- **单说话人 + SIM 判别弱** —— LJSpeech 单说话人使 SIM 近 ceiling、易被少数高杠杆点带动；SIM 仅 secondary；多语种协议（X11）已实现未跑。
- **reward 为 automatic-metric（16kHz WER+SIM+UTMOS）、非 perceptual** —— 未做 ABX/MOS 前不得称 naturalness；dots.tts 48kHz 优势对它不可见。
- **无固定生成 seed → 再合成方差**；bootstrap CI 不覆盖 re-synthesis variance。
- **小 held-out（100）→ CI 极宽**；细粒度 ablation 差异 α=0.05 不单独显著。
- **ASR→表达力外推未验证**（theatrical / emotional / code-switching）。
- **reward-hacking 未复现（honest negative，X7 已收口）** —— 非「待跑」，是已报告的诚实负面（Contribution 4 降级）。
- **工程风险兼局限**：四前向未共享 (x0,t)（最高优先级，`docs/04` 风险②）、full-param DPO OOM（风险⑦）、流式/离线 SIM 不可比 + X4 崩坏臂流式 n 〔待核实〕（风险④/ADR-17）、公开集采样率/许可 〔待核实〕（风险⑥）、open-SOAR `soar_noise_scale=0.5` 未 ablation。
- **水印模块缺失** —— released code 略去 watermarking，建议下游施加 SilentCipher/AudioSeal。`PAPER` Ethics。

## 四、未来前景（Future Prospects）

- **推荐对齐方向（总纲）**：既不把 `L_FM` 当 reward、也不 self-train on reward-selected outputs —— ① open-SOAR on-manifold self-correction、② **reward-weighted regression to real targets（已落地 X6b）**、③ differentiable-vocoder reward backprop（未实现）、④ learned value/preference head（未实现）。`PAPER` §8、ADR-10、`docs/06` §7.2。
- **On-manifold reward-free self-correction（open-SOAR）训向真实目标** —— production 建议：**先在 held-out 对上测似然↔reward 耦合符号，再花 GPU-week**。`README`。
- **标题升格 continuous-latent class** —— X10 已同号复现、结论 architecture-level；但 ADR-14 诚实封顶 N=2，不外推 discrete-token。
- **continuous-latent DPO 的 scaling 未探索** —— backbone > Qwen2.5-1.5B、语料增大、online/iterative DPO、distillation 后对齐能否存活。`PAPER` §7。
- **水印-对齐兼容性验证** —— 列为 future work。`PAPER` Ethics。
- **目标发表场所**：TMLR / *ACL Findings / Interspeech。`docs/09` §⑤。
