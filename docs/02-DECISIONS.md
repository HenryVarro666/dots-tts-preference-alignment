# 02 · 关键决策记录（ADR：背景 / 选择 / 理由 / 被否方案 / 影响）

> 把每个重要设计抉择固化下来，方便日后回看「当初为什么这么定」。

## ADR-1 用 flow-matching 损失当 DPO 的隐式奖励（而非自训 reward model）
- **背景**：连续-AR 无 token log-prob，标准 DPO 不可用。
- **选择**：Diffusion-DPO 思路——用 velocity-MSE 当 −log p 代理。
- **理由**：直接复用 dots.tts 既有 `_compute_fm_loss_term`，零额外网络；理论有据。
- **被否**：①自训显式 reward model 再 PPO（实现重、易不稳、reward hacking 更难控）；②只做 SFT（学不到「相对偏好」）。
- **影响**：方法轻、可复现；命门转移到「共享 (x0,t)」。

## ADR-2 四前向共享 (x0, t)（最高优先级正确性约束）
- **背景**：L_FM 依赖随机 (x0,t)，不共享则 policy/ref、win/lose 不可比。
- **选择**：`fork_rng` + 固定 RNG state 包住 FM 采样，四前向复用同一份。
- **理由**：Diffusion-DPO 同样共享时间步；不共享 → 似然比失效 → 训不出偏好。
- **被否**：各前向独立采样（错误，会引入方差淹没信号）。
- **影响**：实现需小心；列为 04-RISKS 风险②、代码注释高亮。

## ADR-3 多目标 z-norm 奖励（WER+SIM+UTMOS），并**故意保留**仅-WER 臂
- **背景**：只压 WER 易牺牲自然度/音色（Seed-TTS 口述、05 §3.4）。
- **选择**：默认多目标(0.4/0.3/0.3)，按候选池 z-norm；另设 `dpo_weronly` 对照臂。
- **理由**：多目标回答 RQ1；仅-WER 臂**主动复现 reward hacking**（RQ3），是项目最有冲击力的负面结果。
- **被否**：只报多目标好结果（缺少反例就缺说服力）。
- **影响**：奖励权重成为核心操纵变量；结果三表之一专门给 reward hacking。

## ADR-4 候选多样性靠超参网格 + 逐候选 seed（因 generate 无 seed 参数）
- **背景**：`DotsTtsRuntime.generate()` 无 seed（已读源码确认）。
- **选择**：`num_steps×guidance×speaker` 网格 + 每候选 `seed_everything`。
- **理由**：在 API 约束下务实制造可控差异。
- **被否**：改 dots.tts 源码加 seed（增加耦合与维护成本）。
- **影响**：需在 reward 阶段抽查奖励方差确认多样性足够（风险①）。

## ADR-5 流式设为一等评测轴；流式克隆仅 x-vector
- **背景**：用户重视流式；dots.tts 1T1A 流式**拒 prompt_text**（源码 :117）。
- **选择**：离线+流式双模评测；流式用 prompt-audio-only 条件。
- **理由**：要 claim「增益迁移到流式」须走真实流式路径；x-vector-only 是 dots.tts 的硬约束。
- **被否**：拿离线结果替代流式（解码 schedule 不同，不成立）。
- **影响**：流式/离线 SIM 非严格可比，报告时分开标注。

## ADR-6 full-param(H100) vs LoRA(A6000) 双轨；LoRA 时 ref=disable_adapter
- **背景**：2×A6000(48GB) 全参 DPO + 冻结 ref 偏紧。
- **选择**：默认全参(H100, ZeRO-2)；A6000 走 LoRA，ref=关掉适配器的同一模型。
- **理由**：LoRA 省掉第二份模型，显存大降——**纯可行性/显存动机**（LoRA-vs-full **不**作消融维度承诺，原因见下「当前状态」）。
- **被否**：一律全参（48GB 档可能 OOM）。
- **影响**：定位为**纯可行性保障**（48GB 档不 OOM），**不**承担消融维度。
- **当前状态（撤回 LoRA-vs-full 消融承诺，如实标注）**：该「LoRA vs full-param 消融」**从未执行**；且即便执行也**不可归因**——本仓两轨超参并不对齐：LoRA 轨与 full-param 轨在 **β(0.1 vs 0.5)**、**lr(2e-4 vs 1e-5)**、**max_train_steps(2000 vs 600)** 三处同时不同，任何「LoRA vs full」差异都被这**三重混淆**裹挟，无法剥离到 adapter 维度本身。故**撤回**ADR-6 原「同时作 LoRA-vs-full 消融」的承诺；若日后确做此消融，**必须先对齐 β/lr/steps 三者、只单独变 adapter**，否则结论无效（此三重混淆即 ADR-12 被否方案②所引「改参数反引入新混淆」的教训源头）。本项为 reporting-only 修正，**不改任何已报结论数字**。

## ADR-7 把对 dots.tts 内部的耦合收敛到单一 `dots_preprocess.py`
- **背景**：AudioVAE 编码、x-vector、token schedule 都依赖 dots.tts 内部。
- **选择**：所有耦合放进一个适配器；上游只认统一接口。
- **理由**：dots.tts 版本变动时只改一处；上游可独立测试。
- **影响**：`dots_preprocess.py` 的几处 TODO 是「方法落地」的接缝，需对照源码补全。

## ADR-8 A→B 分阶段、B 门控
- **背景**：用户明确「先做出 A，效果好再推进 B」。
- **选择**：A 完整脚手架先行；B 仅脚手架 + 门控判据，达标才执行。
- **理由**：避免在未验证对齐增益前就投入蒸馏/量化。
- **影响**：B 的核心问题（对齐能否在蒸馏后存活）作为 future-work 级开放问题。
- **当前状态（重定位后，如实标注）**：门控判据「Phase A 对齐增益显著为正」**前提已不成立**——Phase A 的真数据是负面结果（DPO-FM 错配、off-manifold self-train 退化，见 ADR-10/11、docs/06/08）。故 **Phase B（蒸馏+量化）降为远期 future work、未执行、不在本论文范围**；`phaseB/` 仅留脚手架占位。

## ADR-9 DPO anchor 锚 winner 的 FM 声学损失（非 ce/eos）；并要求 pair 具备足够质量差
- **背景**：连续-latent DPO 只优化 winner/loser 的**相对量**（reward_margin），不约束绝对质量；模型最廉价的拉大 margin 方式是「搞烂 loser」，会连带把 winner 的 FM 声学损失一起放飞 → 全局 over-optimization（run0：reward_margin 93–170、winner `fm_w` 从 ~1 爆到 11–86、`reward_acc=1.0` 是欺骗性的）。雪上加霜的是，TTS 设定下文本是条件，名义 SFT anchor 里的 `ce≈0`、`eos≈0.05` → 只锚 ce+eos 的 anchor **形同虚设**，压根没在约束生成质量。
- **选择**：① anchor 改锚 winner 的 **FM 声学损失** `fm_pol_w.mean()`（再叠加 `ce_eos`），让 SFT 项真正锚在 TTS 里非零、决定音质的那一项；② 超参定为 **β=0.5、λ_sft=0.2、max_train_steps=600**（三份 config `dpo_multiobj_fullparam.yaml` / `dpo_weronly.yaml` / `open_soar_selfcorrect.yaml` 已统一为此值）；③ 把「pair 必须有足够奖励差」确立为**数据侧硬约束**，不再指望 loss/β 单独解决。
- **理由**：调参时间线暴露了一个**窄稳定窗口**——anchor 太弱（λ_sft=0.1）→ 退化式全局过拟合（靠搞烂 loser 廉价拉 margin，FM 爆、生成崩）；anchor 太强（λ_sft=0.5）→ 偏好信号被压死（按住 `fm_w` 会连带按住 `fm_l`，因同 prompt 候选声学相似、近似平局，margin→0，DPO 退化成「在 winner 上做 SFT」，dpo loss 卡在 ln2=0.693）。即便取平衡中点（λ_sft=0.2、β=0.3–0.5），可达 margin 仍受**pair 质量差上限**制约：run3（β=0.5）出现**间歇性分离**——多数 step 仍平（margin~0.01），但真有质量差的 pair 会炸开真 margin（step593：margin=0.778、`fm_l`=1.45 vs `fm_w`=0.75；step598：margin=0.478、`fm_l`=1.12 vs `fm_w`=0.62），且 `fm_w` 守在 ~1、anchor 没破。这证明平均 margin 低不是超参问题，而是 188 个 pair 里大多数是近似平局。配套经验：盯**绝对**质量量 `fm_w`，别只看相对 `reward_acc`/`margin`（`reward_acc=1.0` 曾掩盖一次彻底崩坏）。
- **被否**：① 只锚 ce/eos（B-15 已证无效：TTS 下 ce/eos≈0，anchor 等于不存在）；② 纯靠调 λ_sft/β 救场（已证只能在「FM 爆 over-optimization」↔「margin→0 欠拟合」之间摆动，治标不治本——可达 margin 的天花板在数据，不在超参）。
- **影响**：indexing 到 `docs/05` 的 **B-15**（anchor 修复、过拟合诊断）与 **B-16**（窄窗口/数据质量差瓶颈）。FM-loss 作隐式奖励只能分开「真不一样」的 pair → **pair 构造（margin 阈值、更大候选池）与 loss/β 同等重要**。**当前状态（如实标注）**：β=0.5 保留；下一步是统计 pair 的奖励差分布，若多为近似平局则用 margin 阈值重造 pair——此步**尚未执行、仍在诊断中，不得记为「已修复」**。

## ADR-10 DPO-FM 诊断重定位为 preference-likelihood 对齐失败（似然代理本身有效）；intrinsic 确立（偏相关存活，partial −0.392）、头条 Spearman；主线转警示性研究，保留 sft/open_soar 臂
- **背景**：ADR-1 用 `−L_FM` 当 DPO 的隐式奖励（Diffusion-DPO 思路），其前提是「`L_FM` 跟 automatic-metric reward 同向」。决定性探针 `alignment/probe_fm_reward.py`（全量 **N=188** pair × K=16 MC，win/lose 共享同一 (x0,t)、no_grad）实测：去噪 FM margin（=`L_FM^lose−L_FM^win`）与 reward 差**反相关**——稳健量 **Spearman ρ=−0.187（p≈0.01、ρ²≈3.5%、按 Cohen 属弱单调）**为头条，**Pearson −0.411（p≈1e-8）并列为「杠杆放大的线性系数」**（N=188 临界 |r|≈0.143、两者均过线）；同时 FM 对随机 winner/loser 平均无系统偏好（**82/188 (44%)** 为正、均值 **−0.0071**、win_rate **0.47**，binomial p=0.093、略低于 0.5 但不显著、大半 near-tie 产物）。这把 ADR-9（B-15/B-16）那条「调不动」的调参史从「超参/数据」上推到**方法层**：FM 既对 winner 无平均偏好（→ margin→0 欠拟合）、又与 reward 反相关（→ 指错方向）。
- **诊断重定位（C6，最重要）**：**不再说「`L_FM` 错配 / intrinsic to `L_FM`」**。`L_FM` 是**有效的似然代理**——`open_soar` 用同一 `L_FM`、似然对齐的偏好训得满分即证据。真正失败的是 **automatic-metric reward 导出的偏好（在 guidance 多样候选池上 best-vs-worst）与模型自身 flow 似然反向**——教科书级 **likelihood-vs-quality / classifier-free-guidance off-manifold** gap（cf. Theis et al. 2016；Ho & Salimans 2022；Gao et al. 2023 reward over-optimization）。两层须分清：**likelihood-surrogate validity（完好）** vs **preference-likelihood alignment（真失败）**。一句话：likelihood-based DPO 在 reward 偏好呈 off-manifold 属性时是**错的工具**；正路是**似然对齐的偏好**（open_soar）或**非似然目标**（winners 上 reward-weighted regression / 经可微 vocoder 直接 reward 反传 / 学习式 value 头）。novelty 重定位为「已知 likelihood-quality gap 在连续-latent flow-matching TTS 上的**领域量化** + 该架构**首个（among the first, to our knowledge）** DPO 实例 + open-SOAR」，**删「首次量化 / 中心发现」式措辞**。
- **guidance-confound 已由 `probe_analysis.py` 裁决：intrinsic 确立（偏相关存活，partial −0.392）**：旧元数据探针 `candidates/inspect_guidance_confound.py`（纯元数据 join pairs↔candidates_index，188 对、0 join 失败）测得 winner/loser 三组生成设置统计上无系统差异、与 reward 差仅弱相关——guidance_scale：winner **1.114** vs loser **1.093**（差 +0.021；winner 更高仅 39%、更低 29%、相等 32%；Pearson(reward差,guidance差)=**+0.108**）；num_steps：**11.85** vs **10.44**（差 +1.42；winner 更高 51%；Pearson **+0.118**）；speaker_scale：**1.371** vs **1.339**（差 +0.032；Pearson **+0.108**），三组 **|Pearson|≤0.12**。**但第一轮审稿（`docs/07` C1/C5/DA）指出此处测错了量**（confound 测的是 corr(reward-gap, setting-gap)，**该测的是 corr(FM-margin, setting-gap)**），故旧测属接受零假设的 under-powered（三相关全为预测方向、CI 上界达 +0.26）。`alignment/probe_analysis.py` 已换对量并跑出：**(1) confound（FM-margin×setting-gap）**——guidance r=−0.067(ns)、**num_steps r=−0.237（显著、CI[−0.360,−0.102]）**、speaker r=−0.067(ns)，即 **num_steps 是真实但温和的混淆**、guidance/speaker 无关；**(2) 决定性偏相关** corr(FM-margin, reward-gap | guidance,num_steps,speaker) = **partial r=−0.392，95%CI[−0.548,−0.209]，显著**——原始 Pearson −0.411 控住全部生成 knob（含 num_steps）后 → −0.392（几乎不变），**反相关存活 partialling、不被 num_steps 解释**。**裁决：intrinsic 确立**（反相关不是生成 knob 的产物）。**严守 C6**：此 intrinsic ≠「intrinsic to `L_FM`」（`L_FM` 仍有效、open-SOAR 为证），诊断仍是 preference-likelihood 对齐失败 / off-manifold winner。
- **统计严谨性（全量 N=188，已收紧 + 诚实修正）**：N=188 临界 |r|≈0.143，**Pearson −0.411（p≈1e-8）与 Spearman −0.187（p≈0.01）双双显著**（n=24 时 Spearman 不显著的弱环已消除）。单次 margin **std=0.0892 ≫ |mean| 0.0071**，印证单步信号高噪、须 MC 去噪后才看清「平均无偏好」（binomial 82/188 vs 0.5 **p=0.093**，略低于 0.5 但**不显著**，故此项大半是 near-tie 数据产物、不作独立 intrinsic 证据）。**修正**：早期 n=24 pilot 表观更强（4/24 为正、win_rate 0.33、Pearson −0.496、Spearman −0.302），其「winner **系统性** FM 更差」是小样本 / 高杠杆点的**高估**——全量回归到 win_rate **0.47**、44% 为正。故头条改用稳健的 **Spearman ρ=−0.187（ρ²≈3.5%、弱单调）**、**Pearson −0.411 并列标注为「杠杆放大的线性系数」**；平均效应（winner 系统性更差）不再作主结论，n=24 仅留作 pilot。
- **选择**：① **暂缓盲目放大**（不再加训练步数 / 不再造更多同构 pair / 不强推「DPO-FM 是可用配方」的叙事）；② **诊断重定位**——从「找一个能用的 DPO-FM 配方」转向**机理性/警示性研究**，标签从「`L_FM` 错配」改为「**preference-likelihood 对齐失败**」（似然代理本身有效）；③ **intrinsic 确立**——`probe_analysis.py` 换对量后，偏相关 corr(FM-margin, reward-gap | guidance,num_steps,speaker)=**partial −0.392（CI[−0.548,−0.209]、显著）**存活，反相关不被任一生成设置（含温和混淆 num_steps r=−0.237）解释（**C6：非 intrinsic-to-`L_FM`，诊断仍 preference-likelihood/off-manifold**）；④ **头条 Spearman ρ=−0.187**（Pearson −0.411 并列为杠杆放大的线性系数）；⑤ **保留 `sft` 与 `open_soar` 两臂**作为不依赖「`L_FM` 当 logprob 且偏好须顺似然」的对照/建设性臂；⑥ **下一步** = 跑 `probe_analysis.py`（偏相关裁决 intrinsic）+ 评测两条建设性臂的 held-out 增益。
- **理由**：`sft`（仅在 winners 上监督 FM，不做 win/lose 的 `L_FM` 对比，只把模型拉向高质量音频）与 `open_soar`（reward-free、偏好建立在「轨迹洁净度」而非外部 reward、且与似然同向）**结构上不踩这个对齐坑**，即使 DPO-FM 被证伪它们仍是有效臂——是当前最稳妥的保底路线。诊断标签定为「preference-likelihood 失败 + intrinsic 确立（偏相关存活）」，是因为审稿正确指出：似然代理（`L_FM`）有效性与偏好-似然对齐是**两层**，open_soar 训得满分恰证前者完好——故 intrinsic 仅指「反相关不是生成 grid 的产物」（由换对量后的偏相关裁决），**不是**把反相关归因到 `L_FM` 本身；后者证据不足，仍按 preference-likelihood 对齐失败处理。
- **被否方案**：① 直接判 DPO-FM 失败并删臂——仍**过早**，DPO-FM 的负面结果本身是论文 §6/§7 的核心机理证据，应留作对照；② 继续加大 β/步数/数据规模硬刷 margin——已被 B-15/B-16 证明只在「过拟合 ↔ 欠拟合」间摆动，偏好方向不顺似然时放大只会更糟；③ 把 n=24 pilot 的单点量级（−0.496/−0.302、win_rate 0.33、4/24）当全量定论——全量 N=188 已证 win_rate 回归 **0.47**、44% 为正，头条以稳健 **Spearman −0.187** 为准；④ **据旧（测错量的）confound 断言 intrinsic /「guidance-confound 已排除」**——被审稿否决：旧 confound 测错了量、属接受零假设；intrinsic 须由**换对量后的偏相关**裁决（现已存活：partial −0.392），不得据 under-powered 的旧测下结论。
- **影响**：indexing 到 `docs/05` **B-17** 与 **`docs/06-核心发现-FM损失与奖励错配.md`**（完整数据/机理/逐对佐证）。贡献定位：从「一个能用的 DPO 配方」转为「**机理性警示**——在 **dots.tts** 上把 likelihood-based DPO/Diffusion-DPO 直接搬到连续-latent flow-matching TTS，当 automatic-metric reward 偏好呈 off-manifold 属性时是错配的；**可能架构特定（待 VoxCPM 等二次复现）**，故收窄到 dots.tts、不外推整类」。建设性候选方向（非 FM-loss-DPO）：winners 上的 reward-weighted regression、经可微 vocoder 的直接 reward 反传、学习式 value/preference 头取代「`L_FM` 当 logprob」。**当前状态（如实标注）**：诊断重定位为 **preference-likelihood 对齐失败**（似然代理 `L_FM` 本身有效，open_soar 为证）；**intrinsic 确立**（`probe_analysis.py` 偏相关 corr(FM-margin, reward-gap | guidance,num_steps,speaker)=**partial −0.392、CI[−0.548,−0.209]、显著**存活；num_steps r=−0.237 温和混淆但被偏相关控住；**C6：非 intrinsic-to-`L_FM`，诊断仍 preference-likelihood/off-manifold**）；头条稳健 **Spearman −0.187（ρ²≈3.5%）**、Pearson −0.411 为杠杆放大的线性系数。早期 n=24 pilot 的平均效应（win_rate 0.33、4/24 为正、Pearson −0.496）系小样本**高估**、仅留作 pilot。结论为**过程性重定位**：intrinsic 指反相关非生成-grid 产物（已裁决），但**不等于**断言 `L_FM` 本身内在错配——诊断仍是 preference-likelihood 对齐失败。

## ADR-11 第二轮实验程序（P0–P4、X1–X13）：从「更多崩坏案例」转向「隔离变量 + 建设性出路 + 架构/语种泛化」
- **背景**：ADR-10 把主线定为机理性警示研究，已立三根支柱——(1) preference-likelihood 对齐失败（似然代理 `L_FM` 本身有效，open_soar 为证）；(2) intrinsic 确立（`probe_analysis.py` 偏相关 partial −0.392，控住 guidance/num_steps/speaker 仍存活）；(3) 头条稳健 Spearman −0.187（Pearson −0.411 为杠杆放大的线性系数）。但 Table 1（n=100）+ 第一轮审稿（`docs/07`）暴露**四个 caveat**，是当前证据链的真实裂缝：① `sft` 崩坏（n=100：WER 0.545/SIM 0.673/UTMOS 3.917）与「小数据 SFT 本身不稳」**混淆**——无法判定退化来自「被拉向 off-manifold winner」还是「数据太小」；② `dpo_multiobj` 灾难（n=75 + 25% 生成失败、WER 0.752/SIM 0.365/UTMOS 2.841）的 25% 究属 graded 退化还是 optimization divergence **证据不一**（X2/X3 已落地：训练 `fm_w` 稳 ~0.74、未二次爆、margin 仍小 0.065 → **训练未发散**；交叉表 34% vs 48% 偏 divergence；**合判 = 生成时子集崩**），**RQ3 的 reward-hacking 在 DPO-FM 框架内未复现**；③ 仅 **dots.tts 单模型**，「可能架构特定」只是猜测、未证；④ 仅 **LJSpeech 单语种**、无流式 Table 2、无 EmergentTTS、无建设性出路的**实证**（仅在 §6/§7 论述、未跑）。

## ADR-12 审计驱动加固（12 路对抗核验，0 blocker；残留全为 reporting-only）
- **背景**：ADR-10/11 立稳「preference-likelihood 对齐失败 + intrinsic 确立（partial −0.392）+ 头条 Spearman −0.187」三支柱后，对全证据链做了一轮**12 路对抗核验**——逐条尝试推翻设计/选择/参数本身（12 路按来源编码：统计 **S1–S5**、devil's-advocate **D1–D3** 为**本轮审计新指派**的疑点码；**project P2 / confound C1·C2 / 贯穿全篇的 C6 两层切分**则承自第一轮审稿 `docs/07`）。
- **核验结论（最重要）**：**设计 / 选择 / 参数本身经得起核验、0 blocker**——12 路全部落在「**reporting-only**」（措辞软化、补已算出的硬数字、或加可选独立锚脚本），**无一要求改 JSONL schema、改「四前向共享-(x0,t)」契约、改奖励权重 (0.4,0.3,0.3)、或推翻任一已报结论数字**。即：方法是对的，要加固的是**怎么把它讲清楚/防御住**，而非方法本身。
- **选择（A/B/C 三类动作 + 去向；与硬约束「只增措辞/硬数字/新脚本」一一对应）**：
  - **A 类（措辞-only；PAPER 英文版 / docs 中文版语义须一致、不得各写各的）**：① **LINEAR**（S4）——偏相关用线性 OLS 残差化、只剔 {guidance,num_steps,speaker} 的线性投影，措辞从「控住全部生成 knob」软化为「**线性**控住全部生成 knob」；点明 num_steps(NFE) 可能**非线性**作用于 velocity-MSE，故偏相关的 intrinsic 裁决「以线性设定为条件」，决定性**非参**控制留给 **X5 settings-matched(setting_gap≡0，消线性+非线性+交互)**。② **OPEN-SOAR-REFRAME**（C2）——open-SOAR 训到饱和（by construction、clean-vs-加噪 loser 易分）只证「DPO-FM 机制在似然对齐偏好下可用 + optimizer 正常」，**不**独立证明 `L_FM` 是忠实 NLL 上界；保留「`L_FM` 似然**启发**代理、非忠实 NLL 上界」caveat，决定性独立锚改挂新实验 **X14**（见下）。③ **SIM-HEDGE**（D2）——per-component 的 SIM_gap −0.68 来自单说话人 LJSpeech 近-ceiling、判别力弱的 SIM（可能由少数真有 SIM 差的对带杠杆），故承重证据放更具判别力的 UTMOS_gap −0.60 与方向明确的 WER_gap +0.41，SIM −0.68 仅作带 hedge 的次要佐证。④ **WEIGHT-SIMPLEX**（P2）——(−WER)/SIM/UTMOS 三轴各自都与 FM-margin 反相关、聚合 reward 是三轴非负加权和，故头条符号在整个权重单纯形上不可翻；per-component 等价于检验权重的**极端顶点**、严格强于权重扫描，**不**对 (0.4,0.3,0.3) 另做敏感性扫描。⑤ **SOAR-NOISE**（P2）——`soar_noise_scale=0.5` 未 ablation、无文档化依据，但 by-construction 它只标定 loser(扰动样本)的 off-manifold 程度、winner 恒为干净真实音频(on-manifold)，故只影响 open-SOAR 改善「幅度」稳健性、**不**威胁方向/头条，也不能把 open-SOAR 变成 off-manifold self-training。⑥ **TWO-STATS**（S1）／**FDR-VENUE**（S2）／**NEAR-TIE-SPLIT**（D1）——两系数永远同报（头条 Spearman 抗高杠杆点、intrinsic 用 Pearson-族偏相关控混淆，回答**不同问题**，杠杆已由 trim/LOO/高-gap 独立控住，非「偷用更大的数」）；偏相关是唯一**预设确证终点**（Bonferroni/14 后 CI 上界仍 <0），合法 FDR 场所是 >100-CI 的消融网格（`main_table`/`reward_hacking`/Table 1–3）而非单方向稳健性检查；显式区分 **FM-margin near-tie**（真实、win_rate 0.47、已降级非头条）≠ **reward-gap near-tie**（实测 0%、中位 1.39，对被充分分开）。
  - **B 类（硬数字-only；把已算出的稳健性量补进正文/附录，不改任何结论数字）**：① **HONEST-CONFOUND**（S4）——主动**公布** num_steps 混淆 r=−0.237、再展示控混淆后系数几乎不动（−0.411→−0.392）= 保守诚实（藏掉它才是作弊）。② **ATTENUATION**（S5）——K=16 测量噪声与独立计算的 reward_gap 不相关，经典 regression dilution 只把 |相关| 向 0 衰减，故 Spearman −0.187 / partial −0.392 是**保守下界**（disattenuation 只增不减）；高-gap 子集反相关反而更强（与噪声伪影预测相反）→ 写成 rebuttal **正面**论据。③ **X1-DOWNGRADE**（S3）——高-gap 分层（两档阈值均预设、全部上报）：top-50% ρ=−0.407(n=94)、top-25% ρ=−0.440(n=47)，CI 均排除 0，故非 near-tie 稀释伪影；杠杆已由 trim(−0.282)/LOO(0.038)/高-gap(≈2×) 独立控住；但因截取扩大了预测变量动态范围、系数变大部分机理可预期，**不**主张真有质量差时效应更强（binomial p=0.093 是独立 mean-effect 符号检验、非相关检验、不作证据）。④ **STEP-BUDGET**（C1/D3，caveat1）——open-SOAR(600) vs sft(1500) 同规模/同优化器族「但步预算不同」的混淆，由 X4 `sft_groundtruth@1500`（on-manifold、同 SFT 目标、仅变 target 流形位置）在跑出后消除；佐证：`dpo_multiobj` 仅 600 步即崩、唯一 1500 步的 sft 居中 → 步数与崩坏非单调（数据待 GPU）。
  - **C 类（新脚本-only；本机仅 `py_compile`/`bash -n`、真实运行在 GPU，登记 `docs/05` §0 速查表第二轮表）**：① 新实验 **X14**（`L_FM` 似然有效性独立锚，见下）；② FDR-VENUE 配套——对 >100-CI 消融网格（`main_table`/`reward_hacking`）跑 Benjamini-Hochberg 校正 + 偏相关确证终点的 Bonferroni/14 复核（`results/aggregate_results.py` 扩展，**JSONL schema 不变**）。
- **理由**：警示性研究最易被攻击的不是「崩坏样本不够多」，而是「头条相关是否被混淆/杠杆/测量噪声/循环论证撑起来」。逐条核验后这些攻击面要么已被**已算出的数字**关闭（confound −0.237、杠杆 trim/LOO、disattenuation、高-gap 分层），要么是**讲法**问题（线性 caveat、两统计量分工、权重单纯形、FDR 场所）——故定级 **0 blocker**：不动方法，只补「防御层」。把核验过程**公布**（尤其 HONEST-CONFOUND / ATTENUATION 主动亮出对自己不利的量再证其无害）本身即保守诚实的体现。
- **被否方案**：① **不做核验直接投**——12 个攻击面任一被审稿命中（尤其 num_steps 混淆、near-tie 稀释、线性偏相关 caveat）都会被打回；② **把残留当 blocker、回炉改方法/参数**——过度反应，核验已证设计/选择/参数本身合理，改它们反而引入新的未对齐混淆（cf. ADR-6 的 LoRA-vs-full **三重混淆**教训）；③ **用 wording 把 `L_FM`-validity 残留也糊过去**——不诚实：该残留是真的「open-SOAR 饱和 ≠ 忠实 NLL 证明」，须由**独立实验 X14** 而非措辞关闭。
- **影响**：A 类落 `docs/06`／`docs/08`(PAPER)／`docs/07`(rebuttal)；B 类落 `docs/06` 正文 + `results/` 表 + `docs/07`；C 类登记 `docs/05` §0。**引 `docs/05` 审计 pass**：本轮 12 路对抗核验在 `docs/05` 审计章记为 **pass（0 blocker、残留 reporting-only）**。**当前状态（如实标注）**：A/B 类为措辞/已算数字的 surfacing、不改任何已报结论；C 类（X14、FDR 校正脚本）为**脚手架/计划态，本机仅 `py_compile`/`bash -n`、结果待 GPU，不得记为「已完成/有结论」**。

**X14 · `L_FM` 似然有效性独立锚（并入 ADR-12 的新实验决策条目；C2 残留的决定性关闭实验、可证伪；接 ADR-11 的 X1–X13 程序）**
- **背景**：ADR-10 的 **C6** 把两层分清——**likelihood-surrogate validity（`L_FM` 是否忠实似然代理，完好？）** vs **preference-likelihood alignment（偏好是否顺似然，真失败）**。诊断结论挂在「前者完好」上，但其现有证据（open-SOAR 用同一 `L_FM`、似然对齐偏好训得满分）经 OPEN-SOAR-REFRAME（C2）核验**只证机制可用 + optimizer 正常、不独立证 `L_FM` 是忠实 NLL 上界**——clean-vs-加噪 loser by-construction 易分、饱和是预期的。故「`L_FM` 似然有效」当前仍是**启发代理**而非被独立锚定的事实。
- **选择**：新增独立锚实验 **X14**，不依赖 open-SOAR、不依赖 reward 偏好，直接检验 `L_FM`(velocity-MSE) 与真实似然的一致性，**typicality 首选**：① **typicality 检验（首选）**——在 dots.tts 自身 flow 下比较真实录音 vs 模型采样的 `L_FM` 分布：忠实似然代理要求真实样本落在**典型集**（`L_FM` 集中、非系统性偏离极端），若真实音频系统性 atypical 则代理可疑；② **ODE-NLL 交叉验证（待核实可行性）**——flow-matching 经 probability-flow ODE（瞬时变量替换 / CNF，cf. Chen et al. 2018；Lipman et al. 2023 flow matching）可算**精确 NLL**，与 `−L_FM` 求相关：强正相关 → 代理忠实，否则不忠实。〔需核实〕dots.tts 的 AudioVAE + flow 是否暴露可积分的 velocity field 以跑 ODE-NLL（接缝按 `docs/04` 风险登记体例标注）。
- **可证伪规则（预设）**：**确认** `L_FM` 有效（→ 维持 C6「似然代理完好、失败在 preference-likelihood 对齐」诊断）当且仅当——真实音频 `L_FM` 落在典型集内（集中、非系统性偏离）**且/或** ODE-NLL 与 `−L_FM` 显著正相关；**证伪**（→ 诊断须部分回退至「intrinsic-to-`L_FM`」、削弱 C6 两层切分）当——真实音频系统性 atypical **或** ODE-NLL 与 `−L_FM` 反相关/无关。无论哪个方向，X14 都把现挂在 open-SOAR 上的弱锚换成**独立、可证伪**的强锚。
- **被否方案**：① **继续用 open-SOAR 饱和当 `L_FM`-validity 证据**——C2 已证其只证机制可用、不证忠实似然；② **用 ELBO/单步 velocity-MSE 直接当 NLL**——`L_FM` 是似然**启发**代理、非忠实下界，正是待验命题，不能拿待验当已验（循环）。
- **影响**：登记 `docs/05` §0 速查表（C 类新脚本）；脚本去向 `alignment/`——typicality 探针**复用** `probe_fm_reward.py` 在「四前向共享-(x0,t)」契约下的 `L_FM` 计算（**契约不变**），ODE-NLL 接缝标〔需核实〕。**当前状态（如实标注）**：**X14 typicality 已跑（n=188）、结论 inconclusive**——diff=winner−real=+0.0007（95%CI[−0.0020,+0.0032]、Wilcoxon p=0.69、不显著），real `L_FM`≈winner ⇒ **既不确认也不证伪** `L_FM` 有效性。按预设可证伪线：**保留 heuristic/非忠实 NLL caveat、C2 不关**（现有据可依）；但**也不证伪 C6**（real 非系统 atypical ⇒ 无证据 `L_FM` 退化）。决定性独立锚未拿下；ODE-NLL 子协议(a) 因 8 接缝〔需核实〕+typicality null 提示无大 gap 而**不投入**。完整裁决见 ADR-15。

## ADR-13 X5 settings-matched 复探针：以最强设计（setting_gap≡0）确证 intrinsic、头条正式切换 Spearman；承接/超越 partial −0.392
- **背景**：ADR-10/11/12 的 intrinsic 裁决挂在 `probe_analysis.py` 的**统计侧偏相关**（partial r=−0.392，控住 guidance/num_steps/speaker 的线性投影）上；但 ADR-12 的 **LINEAR(S4)** caveat 已点明偏相关只「**线性**控住生成 knob」、num_steps(NFE) 可能非线性作用于 velocity-MSE，决定性的**非参**控制留给 X5（ADR-11 第二主线、`candidates/generate_candidates.py --fixed-setting`）。X5 已跑出。
- **设计（最强）**：winner/loser **生成设置完全相同**（同 guidance/num_steps/speaker，**仅 seed 变**）→ **setting_gap ≡ 0 对全部 188 对成立**。这是 intrinsic 问题的**最强设计**——靠**配对设计无条件**兑现 setting 控制（一举消去线性+非线性+交互混淆，严格强于偏相关的线性残差化），而非靠统计建模。join **188/188**、每 prompt 1 对、prompt-level 独立。**confound / 偏相关段按设计 SKIP**：setting_gap 恒为 0 → corr(FM-margin, 常数)=NaN、对常数 partialling 是 no-op（再做即循环）；setting 控制已由配对设计达成。
- **头条（C4）**：settings-matched 对上 FM_margin × reward_gap——**Pearson r=−0.489（r²=0.240）95%CI[−0.616,−0.317]、显著**；**Spearman ρ=−0.216（ρ²=0.047）95%CI[−0.362,−0.054]、显著**（两 CI 均排除 0）。**Pearson/Spearman 比 = 2.26（>2）→ 高杠杆点主导线性系数** → 稳健/诚实**头条仍是 Spearman ρ**。杠杆佐证：剔 top-5% |reward_gap|（10 对）→ Pearson −0.336；LOO 删 #103（fid=LJ001-0109、reward_gap=+3.00）→ Pearson 翻成 +0.024（Pearson 脆弱/杠杆驱动，Spearman 稳定）。
- **高-gap 子集存活（X1，回应审稿「win_rate 0.47、多为近平局」）**：full n=188 Spearman **−0.216[−0.362,−0.054]**；top-50% n=94 **−0.318[−0.504,−0.100]**；top-25% n=47 **−0.533[−0.678,−0.310]** → **真有质量差时反相关更强 → 非近-平局伪影**。
- **去噪 FM margin（MC K=16）**：94/188（50%）为正、均值 **−0.0063**、单-margin SD=0.1010（噪声）、win_rate **0.53**、binomial **p=1.000** vs 0.5 → 去噪后 FM 对 reward-winner **无系统偏好** → **「`L_FM` 不是有效的隐式 reward——这是方法本身的一条边界」**（preference-likelihood 对齐失败这一论文主论点的再确证；C6：非 intrinsic-to-`L_FM`，`L_FM` 仍是有效似然代理）。
- **per-component（R2/R3，join 188/188）**：corr(FM_margin, 分量 gap)——**WER_gap r=+0.517[+0.299,+0.753]（正）**、**SIM_gap r=−0.765[−0.882,−0.548]（负、最强）**、**UTMOS_gap r=−0.716[−0.841,−0.501]（负）** → 反相关由 **SIM & UTMOS（负）** 驱动、WER **正**相关。给社区的开问：是「弃 FM-as-reward」还是「只修 reward 组成」（X5 实测实质偏前者：WER_gap 原始 +0.517但 reward 偏好低 WER→reward-对齐 −WER 上 −0.517、三轴 reward-对齐全反向、聚合为非负加权和符号不可翻 → 整体弃 FM-as-reward，见 WEIGHT-SIMPLEX）？（SIM_gap 杠杆 B3：剔 top-5% → −0.445 仍显著、LOO 删 #103 → +0.060 → 列**次要**佐证，呼应 ADR-12 **SIM-HEDGE**。）
- **disattenuation（split-half B6）**：r_hh=+0.922、Spearman-Brown r_full=0.959、去衰减 ρ_dis=−0.221（≥|ρ|）→ 上报 ρ 是**保守下界**（K=16 测量噪声只把 |相关| 往 0 衰减）。
- **裁决**：**intrinsic 经最强设计确证（CONFIRMED）**。据脚本自注「据此改 §6.7：偏相关存活 → 保留 intrinsic（但头条换 Spearman）」——**intrinsic 保留**；**头条系数正式切换为 Spearman**；现由 **settings-matched 配对**背书（**无条件强于**它所**承接/超越**的 partial −0.392，与 `probe_analysis.py` 偏相关互证、不互替——X5 是 ADR-11「物理 vs 统计」双证据中的**物理侧**）。
- **被否方案**：① 仅凭偏相关 partial −0.392 收口 intrinsic——只线性控混淆、留 NFE 非线性 caveat（ADR-12 LINEAR）；X5 配对设计无条件关闭。② 对 setting_gap≡0 仍跑偏相关/confound——对常数 partialling 是 no-op 且循环。③ 把 Pearson −0.489 当头条——比值 2.26 证其高杠杆驱动、LOO 删一点即翻号，仍以 Spearman 为头条。
- **影响**：兑现 ADR-11 第二主线（X5），落 `docs/06`／§6.7（头条 Spearman、intrinsic 确证）；**严守 C6**——此 intrinsic 仍指「反相关非生成-grid 产物」、**不等于** intrinsic-to-`L_FM`（`L_FM` 似然代理有效性由 open-SOAR + 结构化反相关背书；X14 typicality 独立锚已跑、inconclusive，见 ADR-15，未改变 X5 结论）。**当前状态（如实标注）**：X5 结果**已出**并据此正式定头条 / 确证 intrinsic；其余第二轮实验（X4/X6/X7/X10/X11/X14 等）**仍待 GPU、不得记为已完成**。

## ADR-14 X10 VoxCPM 跨架构探针：偏好-似然反相关在独立实现的 continuous-latent TTS 上 confound-free 复现，关闭 EIC CRITICAL #3（N=1 不可泛化）；scope 升至 continuous-latent（N=2 独立实现）
- **背景**：ADR-13（X5）已在 **dots.tts 单模型**上以 settings-matched 最强设计确证 intrinsic（头条 Spearman −0.216）。但 ADR-11 caveat③ / 第一轮 **EIC CRITICAL #3**「仅 dots.tts 单模型 → N=1 无法泛化、反相关可能**架构特定**」仍是开口。X10（ADR-11 第二主线之一、架构泛化）把**同一批 dots 生成的 winner/loser 偏好对**喂进 **VoxCPM** 测其**自身**训练 FM loss，问：反相关是否跨独立架构复现。X10 已跑出。
- **设计（跨架构）**：VoxCPM = **独立实现**的 continuous-latent TTS——**diffusion-AR、tokenizer-free、手写 MiniCPM-4 backbone + 自有 AudioVAE（OpenBMB）**，与 dots.tts（**flow-matching、rednote/SJTU**）**同属 continuous-latent、实现完全独立**。测 VoxCPM **自己**的训练 FM loss（per-sample velocity-MSE，**源码核验 == dots `fm_loss` 同源**；probe self-check：determinism exact、L_FM finite positive 通过），相关 **FM_margin × reward_gap**。两跑（grid pool / settings-matched），与 X5 同纪律。
- **grid（provenance，C5 混淆在场）**：**GRID pool K=16**（`pairs_best_worst`，生成设置 **VARY → confound present**）：**Spearman ρ=−0.087（NOT sig、CI[−0.248,+0.067]）**；Pearson −0.279（sig 但**杠杆驱动**：Pearson/Spearman 比 = 3.20、单 LOO 即翻号）→ **混淆 grid 上稳健秩统计为 NULL**。**作 provenance 上报**——示生成-setting 混淆把效应 **mask** 掉（在 VoxCPM 上 mask 得比 dots.tts 更甚）。
- **头条（settings-matched，C4 confound by construction 消去）**：**SETTINGS-MATCHED K=32**（`pairs_settings_matched`，**setting_gap≡0**、混淆按构造消去）：**Spearman ρ=−0.266 显著、95%CI[−0.413,−0.112]、permutation p_perm=0.0003（R6、cluster-respecting）**为**头条**。Pearson **−0.461** 95%CI[−0.605,−0.285]、**Pearson/Spearman 比 = 1.73（<2 → HEALTHY、非杠杆驱动）**为 **leverage-checked 次系数**（对比 X5 dots 比值 2.26 高杠杆——X10 线性侧反而更健康）。
- **高-gap 子集存活（X1 同款）**：top-50% Spearman **−0.302**、top-25% **−0.368**（均显著）→ **真有质量差时反相关更强 → 非近-平局伪影**，与 dots X5 同模式。
- **per-component（reward-对齐**全反向**，同 dots.tts）**：WER_gap **+0.336 raw**（reward 偏好低 WER → **reward-对齐 −WER = −0.336**）、SIM_gap **−0.673**（剔 top-5% **−0.471** 仍显著）、UTMOS_gap **−0.529**（均显著）→ 三轴 reward-对齐**全反向**，**与 dots.tts SAME pattern**。去噪 FM 平均偏好：binomial **80/188=0.426、p=0.049**、win_rate **0.394** → **FM 平均偏好更-typical 的 loser**（preference-likelihood 对齐失败的再确证）。
- **裁决**：**反相关在 VoxCPM 上 confound-free 稳健复现（CONFIRMED）**，**comparable to / 略强于** dots.tts 自己的 settings-matched X5（**−0.266 vs −0.216**）。**grid null 被解释**：生成-setting 混淆在 VoxCPM 上 mask 效应，settings-matched 配对设计揭示 intrinsic 效应。→ **CLOSES EIC CRITICAL #3（N=1 无法泛化）**：现象是 **architecture-level**，跨 **N=2 独立 continuous-latent 实现**（**flow-matching dots.tts + diffusion-AR VoxCPM**）成立。
- **CALIBRATION（严防过度外推）**：scope 升至「**continuous-latent（flow-matching/diffusion）TTS**」，由 **N=2 独立实现**背书——**NOT「all TTS」、NOT discrete-token TTS、仍只 2 个模型**。头条为 settings-matched **Spearman −0.266**（confound-free 设计）；**grid −0.087(ns) 作 provenance**（示混淆 mask）；**Pearson −0.461 为 leverage-checked 次要**（比值 1.73 健康）。**与 dots X5 同 settings-matched 纪律**。
- **被否方案**：① **拿 grid pool −0.087(ns) 判 VoxCPM 无效应 / 反驳泛化**——混淆未控、把 masked 效应误读为 null；settings-matched 消混淆后 ρ=−0.266 显著（p_perm=0.0003）。② **把 Pearson −0.461 当头条**——虽比值 1.73 健康，仍与 X5/全篇纪律一致以 **Spearman** 为头条。③ **把 claim 升到「all TTS / 架构无关」**——仅 N=2、且两者均 continuous-latent；**discrete-token TTS 未测**，不外推。
- **影响**：兑现 ADR-11 架构泛化主线（X10）、**关闭 caveat③ / EIC CRITICAL #3**；落 `docs/06`（跨架构泛化）。**严守 C6**——此为 architecture-level 的「偏好-似然反相关」、**不等于** intrinsic-to-`L_FM`（`L_FM` 似然代理有效性由 **open-SOAR 饱和 + 结构化反相关本身**背书；ADR-12 的 X14 typicality 独立锚**已跑、inconclusive**，见 **ADR-15**，未改变 X10 结论）。**当前状态（如实标注）**：X10 结果**已出**并据此关闭 EIC CRITICAL #3 / 把 scope 升至 continuous-latent（N=2）；其余第二轮实验（X4/X6/X7/X11 等）**仍待 GPU、不得记为已完成**（X14 已跑、见 ADR-15）。

## ADR-15 X14 `L_FM` 似然有效性独立锚（typicality）：结论 inconclusive——C2 caveat 保留、C6 不回退；放弃 ODE-NLL
- **背景**：ADR-12 OPEN-SOAR-REFRAME（C2）把「`L_FM` 有效似然代理」的现有证据（open-SOAR 饱和）判为 by-construction、不独立；决定性独立锚改挂 X14（typicality：配对比 real 录音 vs reward-winner 的 `L_FM`，问 real 是否系统更典型）。X14 已跑。
- **结果（n=188、dots.tts 自身 flow、复用 `probe_fm_reward`「四前向共享-(x0,t)」契约、K=16）**：diff=winner−real=**+0.0007**、bootstrap 95%CI[−0.0020,+0.0032]、Wilcoxon 双侧 **p=0.6875**、diff>0 占 98/188=0.52；real `L_FM`=0.7769 ≈ winner=0.7776。**不显著**。
- **裁决（守预设可证伪线）**：CI 含 0 ⇒ 真实录音 `L_FM` **不系统低于** winner（**不确认**）、亦**不系统高于**（**不证伪**）→ **inconclusive**。① **保留**「`L_FM` 似然**启发**代理、**非忠实 NLL 上界**」caveat、**C2 不关**（但现为**有据**的 inconclusive、非"待做"）；② **C6 不回退**——real 非系统 atypical ⇒ 无证据 `L_FM` 退化/反似然；`L_FM` 有效性继续由 **open-SOAR 饱和 + 结构化显著反相关本身**背书；③ PAPER §7 Limitations 如实记「独立 typicality 锚 inconclusive」。
- **为什么 null 良性（不伤核心）**：X14 比 real vs **winner**（质量最好的候选）——好 TTS 的 winner 本就与真实录音同样典型、**无 gap 可测**；off-manifold 在 winner vs **loser**（=主探针 FM_margin，显著），与 X14 null 不矛盾。**反相关 / X5 intrinsic / X10 架构级均不依赖 `L_FM` 是忠实 NLL → 不受影响**。
- **被否方案**：① **跑 ODE-NLL 子协议(a)**——8 处〔需核实〕接缝风险高、且 typicality null 提示无大 gap、性价比低 → **放弃**；② **用措辞把 caveat 糊成"已关"**——不诚实（同 ADR-12 被否③）；③ **据此回退到 intrinsic-to-`L_FM`**——过度反应，null 未证伪 C6。
- **影响**：`docs/06` §4.2 heuristic-caveat 段 + ADR-12 X14 条状态已更新；归档 `results/out/x14_lfm_*`。
