## 其它高频 MAJOR（共识）
- **无人类听测(ABX/MOS)** 锚定"perceptual"/"naturalness 退化"；reward 是 16kHz 上算的 WER+SIM+UTMOS(UTMOS 出训练域)，dots.tts 的 48kHz 优势对 reward 不可见 → 未锚定前改称"automatic-metric reward"。(全体)
- **"平均无偏好(win_rate 0.47)"大半是 near-tie 数据产物**，非独立的 intrinsic 证据 → 只靠反相关、且需在**高 gap(非平局)子集**上证明它存活。(EIC/R1/R3/DA)
- **建设性一半(open-SOAR/SFT escape、multi-obj recovers)仅由训练动力学断言**，held-out 全 TBD；"训到满分"≠"音质更好"；open-SOAR loser 是加噪 rollout、FM margin 巨大 → live-training control 近乎**循环论证**，只能算"by construction"。(EIC/R1/R2/DA)
- **脊柱当前不可证伪**：§6.7 把 under-fit 和 active-degrade **两个相反结局都预先算作"印证"** → 必须在解盲 n=100 **前**预承诺一条可证伪规则 + 撤回规则。(DA)
- **Contribution 2 vs 4 冲突**：若 dpo_multiobj 崩坏，它不能同时是"recovers naturalness"的缓解臂。(R2)
- **独立性未验**：188 对嵌套在更少 prompt/单说话人里 → 边缘的 Spearman 显著性脆弱，需 cluster/permutation。(R1)
- **K=16 MC 充分性**：单次 std 0.0892 → 每对 SE 0.0223 ≫ 均值 0.0071 → 衰减(attenuation)使相关被低估；regression-to-chance 部分可能是 K 从 24→16 的产物。(R1)
- **§3.2 把 FM-velocity-MSE 说成"-log p 的变分上界"过强**：CFM 下它只是向量场 MSE 的无偏估计、**非已证 NLL 界**(heuristic)。(R2)
- **headline 数字不可从仓库复现**：probe 只打印 stdout、`pairs_best_worst.jsonl`/`candidates_index.jsonl` 未提交。(R2)
