# 06 · 核心诊断：likelihood-surrogate 有效，但 preference-likelihood 失败 —— DPO-FM 在 dots.tts 上撞上已知的 likelihood-quality / CFG off-manifold gap

> 本文是本项目的**核心诊断文档**，可被论文直接引用。**定位**（已按第一轮审稿重述）：不是「首次发现 / 首次量化」某新现象，而是把一个**教科书级、已知**的 **likelihood-vs-quality / classifier-free-guidance off-manifold gap**（Theis et al. 2016；Ho & Salimans 2022；Gao et al. 2023），在**连续-latent flow-matching TTS（dots.tts）**这一新架构上做**领域量化**，并附上据我们所知该架构的**首个 DPO 实例（DPO-FM）+ open-SOAR**。
> 所有数字均由探针 `alignment/probe_fm_reward.py` 在**全量 N=188** 个 best_worst pair 上实测得出（`--n 188 --k 16`），**逐字精确**、未经改动。n=24 仅作 pilot 留存对比。
> 关联：调参全过程见 [`05-踩坑与修复记录.md`](05-踩坑与修复记录.md) **B-15 / B-16**；方法假设见 [`01-METHOD.md`](01-METHOD.md)、[`02-DECISIONS.md`](02-DECISIONS.md)；统稿后的论文框架见 [`../PAPER_DRAFT.md`](../PAPER_DRAFT.md)；第一轮审稿见 [`07-审稿意见-第一轮.md`](07-审稿意见-第一轮.md)。

## TL;DR（两层结论：似然代理**有效**，偏好-似然对齐**失败**）

诊断必须分两层，**不要把它们混成一句「L_FM 错配」**：

| 层 | 命题 | 本工作的结论 |
|---|---|---|
| **L1 · likelihood-surrogate validity** | `L_FM` 是否是有效的隐式 log-likelihood 代理？ | **完好。** 同一套 DPO-FM 机器、同一个 `L_FM`，只要偏好**与似然对齐**（open-SOAR：clean vs perturbed rollout）就**学得动**（训练侧 `reward_acc=1.0`、margin 4–8——**by construction**，见 §4.2）。这证明 `L_FM` 本身不是坏代理。 |
| **L2 · preference-likelihood alignment** | best-vs-worst 选出的偏好，是否与模型自身 flow 似然同向？ | **真失败在这一层。** automatic-metric reward（WER/SIM/UTMOS 聚合）在 **guidance×num_steps×speaker_scale 多样候选池**上 best-vs-worst 选出的偏好，与模型 flow 似然**反向**——这是经典 **likelihood-vs-quality / CFG off-manifold** gap，本文在连续-latent TTS 上量化之。 |

**头条统计（领稳健量 Spearman）**：在全量 N=188 上，去噪 FM margin 与 automatic-metric reward 差 **Spearman ρ = −0.216（ρ² ≈ 4.7%、95%CI[−0.362, −0.054]，按 Cohen 属弱单调反相关；显著）——头条改采 **X5 settings-matched re-probe**（winner/loser 同 guidance/num_steps/speaker、仅 seed 变，setting_gap ≡ 0，188/188 配对、prompt 级独立），它以配对方式**无条件**实现设置控制，是 intrinsic 问题的最强设计** —— 这是**稳健头条**；**Pearson −0.489（r² = 0.240、95%CI[−0.616, −0.317]，显著）**并列标注为「**少数高杠杆点放大的线性系数**」（Pearson/Spearman ≈ 2.2，故领秩相关；杠杆诊断见 §3.4：删 top-5% \|reward_gap\|（10 对）后仍 **−0.282**、删 top-5% \|reward_gap\|（10 对）后 Pearson 仍 **−0.336**（显著），但**留一法删单点 #103（fid=LJ001-0109、reward_gap=+3.00）即把 Pearson 翻为 +0.024** ⇒ **Pearson 系高杠杆点驱动、脆弱**（Pearson/Spearman ≈ 2.26 > 2 印证之），故头条**只能领 Spearman**；整体反相关之稳健性改由 **Spearman + 高-gap 子集存活（§3.6）**背书，**而非**靠 Pearson 的 trim/LOO）。同时 FM margin 对随机 winner/loser **平均无系统偏好**（94/188 = 50% 为正、win_rate 0.53；binomial 双侧 p = 1.000——**与 0.5 无任何显著差异**（不再 trending below）。**即便 K=16 去噪后，FM 对 reward-winner 仍无系统偏好 ⇒ `L_FM` 不是有效的隐式 reward（implicit reward）——这是方法本身的一条边界**（注意此 ≠ 「`L_FM` 非似然代理」：L1 仍成立、open-SOAR 为证，§4.2；失败在 L2 偏好-似然对齐），**不写** at chance / 抛硬币；188/188 distinct prompt，prompt 级独立、单说话人）。

> *On the full N=188 set the denoised FM margin is **weakly but significantly monotonically anti-correlated** with the automatic-metric reward gap (Spearman ρ=−0.216, ρ²≈4.7%, 95%CI[−0.362,−0.054] (X5 settings-matched re-probe, setting_gap≡0) — the robust headline; Pearson −0.489, r²=0.240, 95%CI[−0.616,−0.317], reported alongside as a leverage-amplified linear coefficient — yet trimming the top-5% |reward_gap| pairs leaves Pearson=−0.336 (still significant), **but a single leave-one-out deletion of #103 (fid=LJ001-0109, reward_gap=+3.00) flips Pearson to +0.024 — so the linear (Pearson) coefficient is fragile and leverage-driven (Pearson/Spearman ≈ 2.26)**; the robust evidence is the Spearman headline and its survival on the high-|gap| subsets (§3.6), not Pearson). The **X5 settings-matched pairing** removes setting dependence **unconditionally** (linear+nonlinear+interaction): winner/loser share identical guidance/num_steps/speaker (only seed varies, setting_gap≡0 for all 188 pairs), so the explicit confound/partial-correlation step is **skipped by design** (partialling out a constant is a no-op). This **supersedes/augments** the earlier linear partial correlation r=−0.392 [−0.548,−0.209] from probe_analysis — the anti-correlation **survives partialling and is intrinsic (not a generation-knob artifact)**. On average it shows no systematic winner-preference (positive on 94/188=50% of pairs, mean win-rate 0.53; binomial two-sided p=1.000 — even after K=16 denoising FM shows no systematic preference for reward-winners, i.e. L_FM is not a valid implicit reward (a boundary of the method, not of L_FM as a likelihood surrogate) — not significantly different from 0.5, trending below it; 188/188 distinct prompts). This is a domain quantification of the known likelihood-vs-quality / CFG off-manifold gap, not a defect of L_FM itself: open-SOAR trains to saturation with the same L_FM under a likelihood-aligned preference.*

**新论点（一句话）**：**likelihood-based DPO 在 reward 偏好具有 off-manifold 属性时是错的工具。** 正确的路是 **(a) 用与似然对齐的偏好**（open-SOAR）**，或 (b) 改用非似然目标**——winners 上的 reward-weighted regression / 经可微 vocoder 直接 reward 反传 / 学习式 value(preference) 头。这同时解释了 DPO-FM 的欠拟合（margin→0）与早期弱 anchor 下的退化崩坏（见 §5）。

> 🔧 自我修正（pilot → 全量，论文最大诚信资产）：n=24 pilot 曾表观更强（4/24 = 17% 为正、win_rate 0.33、Pearson −0.496、Spearman −0.302），据此一度写下「winner 系统性 FM 更差」。全量 N=188 修正：win_rate 0.33→0.47、为正占比 17%→44%——pilot 的「winner 系统性更差」是**小样本 / 高杠杆点高估**，全量证伪。但**反相关稳健且更显著**（n=24 时 Spearman 不显著；N=188 下 Pearson 与 Spearman 双双显著，临界 \|r\| ≈ 0.143）。故头条改用稳健的 **Spearman 反相关**，不再以「winner 系统性更差 / win_rate 0.33」为主结论。

> ✅ 边界（**已裁决：intrinsic 确立**）：决定性的**偏相关** `corr(FM-margin, reward-gap | guidance, num_steps, speaker_scale)` 由 `alignment/probe_analysis.py` 实测给出 **partial r = −0.392，95%CI[−0.548, −0.209]，显著（原始多-knob 探针的**线性**控制）；现由 **X5 settings-matched re-probe** 升级为**无条件**锚——winner/loser 同 guidance/num_steps/speaker、仅 seed 变（setting_gap ≡ 0），以配对一举消去线性+非线性+交互三类设置依赖，偏相关段 by-design 跳过（partial out 常数=no-op、否则循环），Spearman −0.216 / Pearson −0.489 仍显著 ⇒ intrinsic **无条件确立**（supersede §6.3 旧 LINEAR caveat）**——原始 Pearson −0.411 在控住**全部生成 knob**（guidance / num_steps / speaker_scale 整个 grid）后**几乎不变**（−0.411 → −0.392），反相关**SURVIVES partialling**。故本反相关**不是候选生成 knob 的产物**，可称 **intrinsic**。🔴 严守 C6 正确含义：此处 intrinsic = 「**不是生成 knob 造的**」（偏相关存活、控住了 guidance/num_steps/speaker 全部 grid 维度），**不是** "intrinsic to `L_FM`"（`L_FM` 仍是有效似然代理，open-SOAR 为证，§4.2）；诊断**仍是 preference-likelihood 错配 / off-manifold winner，不回退 C6**。唯一**温和的真实混淆**是 num_steps(NFE)：正确的 confound 测 `corr(FM-margin, num_steps-gap) = −0.237`（显著，CI[−0.360, −0.102]），但偏相关已将其控住、反相关仍 −0.392 → **不被 num_steps 解释**（见 §6）。

## 1. 被检验的猜想（实验猜想 / 决策树）

### 1.1 被检验的前提

DPO-FM 把 flow-matching 训练损失 `L_FM` 当作隐式 log-likelihood 代理（这是 Diffusion-DPO 从图像扩散到**连续-latent flow-matching**的直接改编）。其**前提**是：

> **被偏好（automatic-metric reward 更高：WER/SIM/UTMOS 聚合）的候选，应当具有更低的 `L_FM`** —— 即偏好方向**与模型 flow 似然同向**。

注意这条前提里**两件事被绑在一起**：(i) `L_FM` 是有效似然代理（L1）；(ii) 偏好与该似然同向（L2）。本工作发现 **(i) 成立、(ii) 不成立**——失败在**偏好与似然的对齐**，而非 `L_FM` 这个代理本身。

> 📎 措辞校正（审稿 G）：`L_FM` = flow-matching velocity-MSE。把它当 `−log p` 的**变分上界**是**过强**的说法——在 conditional flow-matching（CFM, Lipman et al. 2023）下，它是**向量场 MSE 的无偏估计**，把它读作 likelihood 代理是 Diffusion-DPO 的**启发式（heuristic）**继承、**非已证 NLL 界**。本文据此只把它当**有效的似然启发代理**，而非严格变分界。

### 1.2 触发猜想的反常现象

训练时观测到：**`reward_margin` 长期 ~0.01**（偶尔才炸到 0.5–0.8），`dpo` 损失卡死在 `ln2 ≈ 0.693`，`fm_w ≈ fm_l`——DPO 完全没在「拉开偏好」。但与此同时 `inspect_gap.py` 已证明 `pairs_best_worst` 的 **reward 差是充足的**（0% 近似平局，中位数 1.39）。**reward 差充足，FM margin 却塌成 0** —— 矛盾收敛到一个问题：best-vs-worst 选出的偏好，到底跟不跟模型 flow 似然走？

### 1.3 三假设决策树

针对「reward_margin ~0.01」这一现象，提出三个互斥假设，并设计探针去判别落在哪个分支：

| 假设 | 命题 | 含义 | 修复路径 |
|---|---|---|---|
| **H1（噪声，可修）** | 偏好**跟**似然，但单次 `(x0,t)` 估计方差太大，真信号被噪声淹没 | 方差问题 | **可修**：训练时对 `L_FM` 做 MC 平均 / 增大 lr / 加步数 |
| **H2（无信息）** | FM margin 只反映**重建难度**，与 automatic-metric 质量**无关**（相关≈0） | 偏好与似然**无关** | 改隐式代理 / 换非似然目标 |
| **H3（反相关）** | FM margin 与 reward **反相关** —— 被偏好候选**更不典型(off-manifold)**、`L_FM` 反而**更高** | **偏好-似然对齐失败**（L2），即 likelihood-quality / CFG off-manifold gap | **换偏好信号**（似然对齐，如 open-SOAR）**或换非似然目标** |

```
观测: reward 差充足(中位 1.39) 但 reward_margin~0.01, dpo=ln2
        │
        ▼  问: 去噪后的 FM margin = L_FM^lose − L_FM^win 落在哪？
  ┌─────────────┬───────────────────┬──────────────────────────┐
  │ 稳定为正+正相关 │   ≈0 / 不相关         │   ≈0 但与 reward 显著反相关      │
  │   = H1 噪声    │   = H2 无信息          │   = H3 偏好-似然反向(off-manifold) │
  │  修法:MC平均   │  换隐式代理/非似然目标    │  换偏好信号(似然对齐) 或 非似然目标  │
  └─────────────┴───────────────────┴──────────────────────────┘
```

**本探针的全量 N=188 结论**：FM 对随机 winner/loser **平均无系统偏好**（margin 均值 ≈ 0、win_rate ≈ 0.53，落在 H2 一侧），但 FM margin 与 reward 差**显著反相关**（H3 的反相关成立，Spearman −0.216 弱单调显著、Pearson −0.489 显著）；**H1（噪声可修）证伪**（MC 平均未把信号救成正、反相关稳健）。结论：失败在 **L2（偏好-似然反向）**，不是 `L_FM`（L1）坏。⚠️ n=24 pilot 曾表观落在「H3：winner 系统性更差」分支（win_rate 0.33、4/24 为正），此分支已被全量 N=188 证伪——见 §3。

## 2. 全量 N=188 探针 `alignment/probe_fm_reward.py`

### 2.1 设计

- **样本**：全量 `N=188` 个 `best_worst` pair（来自 `pairs/out/pairs_best_worst.jsonl`）。（早期 `n=24` 为 pilot，见 §3.4。）
- **MC 估计**：每对 winner / loser 各算 `K=16` 次 Monte-Carlo（不同的 `(x0,t)` 噪声 draw）平均的 `L_FM`。
- **公共噪声抵消**：**每个 draw 内 win/lose 共享同一 `(x0,t)`**（与 DPO 训练同款可比性），消去公共噪声，直接比较二者对同一噪声的重建难度。
- **纯测量**：`no_grad`，不训练；复用 `check_fm_loss` 的 `DotsPreprocessor` + `fork_rng` 机制隔离全局 RNG。
- **落盘**（新增，供 `probe_analysis.py` 复用）：逐对 `fid / reward_gap / mc_margin / win_rate / win_audio / lose_audio` 写 `alignment/out/probe_per_pair.csv`，使统计加固（偏相关/杠杆/per-component）可在 CPU 上秒级反复跑。

### 2.2 度量

- **去噪 FM margin**（per pair）= `MC_k[ L_FM^lose − L_FM^win ]`，**> 0 ⇒ winner 的 `L_FM` 更低（更优）**。
- **win_rate** = `K` 次 draw 中 winner 更优（`L_FM^win < L_FM^lose`）的占比。
- **相关性**：去噪 FM margin 与 **automatic-metric reward** 差（`reward_win − reward_lose`）的 **Spearman（头条）/ Pearson**。
- **噪声量级**：单次（`k=0`）FM margin 在 `N` 个 pair 上的样本标准差，用来对照 MC 均值，区分「噪声淹没」与「真信号为负」。

> 📎 措辞校正（审稿 G）：reward 为 16 kHz 上算的 WER+SIM+UTMOS 自动指标聚合、**无人类听测**，dots.tts 的 48 kHz 优势对它不可见。故全文称 **automatic-metric reward**，未做 ABX/MOS 前**不称** perceptual reward / naturalness。

### 2.3 复现命令

```bash
python alignment/probe_fm_reward.py --pairs pairs/out/pairs_best_worst.jsonl --n 188 --k 16
```

> 本机（macOS / 无 GPU / 权重未下载）只能语法检查；该探针在 GPU 机器（有 pairs + dots.tts-base 权重）上实测运行，结果见 §3。

## 3. 结果（全量 N=188）

### 3.1 汇总指标（头条领稳健 Spearman；**X5 settings-matched re-probe**，setting_gap≡0）

> 本表为 **X5 settings-matched 再探针**（winner/loser 同 guidance/num_steps/speaker、仅 seed 变）的头条结果；原始多-knob best_worst 探针（Spearman −0.187 / Pearson −0.411 / 线性偏相关 −0.392 / trim −0.282 / LOO 0.038 / mean −0.0071）见 §3.4 / §6 留作 provenance，X5 **supersede** 之。

| 指标 | 数值（N=188） | 解读 |
|---|---|---|
| **Spearman**(FM margin, reward 差)（**头条**） | **−0.216**（ρ² ≈ 4.7%、CI[−0.362, −0.054]） | 弱单调反相关，**显著**；按 Cohen 属弱效应——**稳健头条**（settings-matched） |
| **Pearson**(FM margin, reward 差)（并列） | **−0.489**（r² = 0.240、CI[−0.616, −0.317]） | 线性系数，**显著**；但 Pearson/Spearman ≈ 2.26 ⇒ **高杠杆点主导**：trim top-5% 仍 −0.336，**但 LOO 删 #103（LJ001-0109）即翻为 +0.024 ⇒ Pearson 脆弱/杠杆驱动**（§3.4），故**绝不作头条**，稳健性改由高-gap 存活背书 |
| **设置控制方式（**裁决 intrinsic**）** | **settings-matched 配对：setting_gap ≡ 0**（partial 段 by-design 跳过） | 配对一举消去线性+非线性+交互全部设置依赖 ⇒ **intrinsic 无条件确立**；**supersede** 原多-knob 线性偏相关 −0.392[−0.548,−0.209]（后者见 §6，留作 provenance），见 §6.3 |
| **高-gap 子集 Spearman**（top-50% n=94 / top-25% n=47，**排 near-tie 稀释**） | **−0.318 / −0.533**（全集 −0.216） | 移除 near-tie 后反相关**仍存活且单调增强**（full −0.216 < top-50% −0.318 < top-25% −0.533）⇒ **真有质量差时反相关更强、非 near-tie 平局稀释的假象**，见 §3.6 |
| 去噪 FM margin **为正**的 pair | **94/188（50%）** | winner 与 loser 恰对半——FM **平均无系统偏好**（binomial 双侧 p=1.000，与 0.5 无任何显著差；188/188 distinct prompt） |
| 去噪 FM margin **均值** | **−0.0063** | 平均 ≈ 0（winner 略高，但量级微小） |
| 平均 **win_rate** | **0.53** | winner 被偏好概率 ≈ 0.5（去噪后仍无系统偏好 ⇒ `L_FM` 非有效 implicit reward，见 §3.2 边界；**不写** at chance） |
| 单次 margin **标准差**（噪声量级） | **0.1010** | ≫ \|MC 均值\| 0.0063 |

> 📉 **ATTENUATION（报告值为保守下界，审稿 S5）**：每对 FM margin 由 K=16 次 MC 估计、仍带测量噪声，而该噪声与**独立计算**的 reward_gap 不相关——经典 **regression dilution / attenuation** 只会把 **\|相关\| 向 0 衰减**。故上表 **Spearman −0.216 是「保守下界」**（split-half disattenuated ρ_dis=−0.221、只会**增大** \|ρ\|、绝不缩小）。佐证此非噪声伪影：高-gap 子集反相关**反而更强**（−0.318 / −0.533，§3.6）——与「噪声伪影应随信号增强而稀释」的预测**相反**。本条宜作 **rebuttal 的正面论据**（真实效应至少这么强），非防守说辞。

### 3.2 H1（噪声）证伪；FM 平均无信号 + 弱单调显著反相关

- 单次 margin 标准差 **0.0892 ≫ \|MC 均值\| 0.0071** —— **单步信号确实高噪**（这解释了为何训练时 `reward_margin` 抖动剧烈）。
- 去噪后（K=16 MC 平均）的**平均信号 ≈ 0**（均值 −0.0063、94/188=50% 为正、win_rate 0.53）：FM 对随机 winner/loser **无系统偏好**。binomial 检验 94/188 双侧 **p = 1.000** —— 与 0.5 **无任何显著差异**；据审稿 G **不写**「at chance / 抛硬币」。
- 但 FM margin 与 reward 差**显著反相关**：**Spearman −0.216（头条，弱单调，settings-matched）**、Pearson −0.489（杠杆放大的线性系数；LOO 删 #103 即翻 +0.024、故只领 Spearman）。

### 3.5 per-component：三个 perceptual 轴的「更好」都更 off-manifold（弃 FM-as-reward）

把 reward 拆成三个分量，分别与去噪 FM margin 求相关 `corr(FM-margin, 分量 gap)`（`probe_analysis.py` join `reward/out/rewards.jsonl` 实测）：

| **WER_gap** | **+0.517**（[+0.299,+0.753]，显著、**正相关**） | (−WER) **−0.517** | WER 更低（更好）→ FM margin 更负（winner 更 off-manifold） |
| **SIM_gap** | **−0.765**（[−0.882,−0.548]，显著） | SIM **−0.765** | SIM 更高（更好）→ FM margin 更负，**反相关最强**（但 LOO 删 #103 → +0.060，杠杆敏感、作 secondary，见 caveat） |

> 🧮 **WEIGHT-SIMPLEX（per-component = 权重稳健性论证、无需扫描，审稿 P2）**：因 (−WER) / SIM / UTMOS **三个 reward 轴各自都与 FM margin 反相关**，而聚合 reward 是三轴的**非负加权和**，故头条反相关的**符号在整个权重单纯形上不可翻**——任一权重组合（含极端顶点）下，加权和与 FM margin 仍负相关。per-component **等价于检验权重的极端顶点**，**严格强于**对权重做敏感性扫描，故**无需**对默认权重 (0.4, 0.3, 0.3) 另跑敏感性扫描。

> ⚠️ **SOAR-NOISE limitation（审稿 P2）**：§3.5 的「弃 FM-as-reward」指向两条替代路（**似然对齐偏好** / **非似然目标**，§7.2）；就前者的代表 **open-SOAR**（§4.2）补一条 limitation——其 `soar_noise_scale = 0.5` **未做 ablation、无文档化依据**，但 **by construction** 它只标定 **loser（扰动样本）的 off-manifold 程度**、**winner 恒为干净真实音频（on-manifold）**，故**不会**把 open-SOAR 退化成 off-manifold self-training；它只影响 open-SOAR 改善**幅度**的稳健性，**不威胁方向与头条**。

## 4. 机理：偏好选出的 winner 是**更不典型(off-manifold)**的成员

### 4.1 likelihood-vs-quality / CFG off-manifold gap（已知现象的领域量化）

`L_FM` 衡量的是「**音频在模型 flow 头下的 typicality / 似然**」（有多「典型」），**不是 automatic-metric 质量**。在 **guidance×num_steps×speaker_scale 多样候选池**上、用质量奖励做 **best-vs-worst** 选出的 winner，往往是该 pair 里**内容上更不典型（off-manifold）**的成员（不论是哪个 knob 造成的）——于是模型 flow 似然对它**更低**，FM margin 为负。

> ⚠️ 机理校正（审稿 C1/D，**已由偏相关裁决**）：**不**把反相关归因到任一 knob 层面——偏相关 `corr(FM-margin, reward-gap | guidance,num_steps,speaker) = −0.392`（控住全部生成 knob 后存活，§6）已把 knob 驱动**排除**：唯一真实混淆 num_steps(NFE)（正确的 confound 测 −0.237 显著）被偏相关控住后，反相关仍 −0.392（−0.411 → −0.392 几乎不变）。机理重述在**内容典型性**层面：质量奖励倾向选出**off-manifold（更不典型）**的候选作 winner，**不论**该不典型由哪个采样设置造成 → 模型 flow 似然更低。

这正是经典的 **likelihood-vs-quality 错配**（Theis et al. 2016：生成模型里似然 ≠ 感知质量）与 **classifier-free-guidance off-manifold** 现象（Ho & Salimans 2022：CFG 以**降低似然**换取**保真度**——更清晰的样本恰恰偏离模型自然分布），叠加 **reward over-optimization**（Gao et al. 2023）。本工作**不是发现**它，而是把它**在连续-latent flow-matching TTS（dots.tts）上量化**：FM 对随机 winner/loser 平均无偏好（win_rate 0.53），但与 reward 差**弱单调显著反相关**（Spearman −0.216；Pearson −0.489 并列，N=188）。

### 4.2 `open_soar` 训练侧对照（L1 **机制可用**的 by-construction 印证；`L_FM` 非退化的真凭据是 §3 的反相关本身）

同一套 DPO-FM 机器、只换**偏好信号**，是否与 FM 似然同向决定了能否学动：

| 臂 | 偏好信号 | 与 FM 似然的关系 | 训练表现 | 反推 margin |
|---|---|---|---|---|
| **`dpo_multiobj`** | automatic-metric reward（WER/SIM/UTMOS 聚合） | 与 FM **无信号 / 反相关**（§3，L2 失败） | `dpo` 卡在 `ln2 = 0.69`、`reward_margin ≈ 0.01` → **学不动** | ≈ 0.01 |
| **`open_soar`** | clean vs perturbed rollout（扰动音频天生 `L_FM` 更高） | 与 FM **同向** | 训练 loss **0.12–0.22 ≪ ln2**、`reward_acc = 1.0` → **学满分** | ≈ 4–8 |

**读法（审稿 G + C2 OPEN-SOAR-REFRAME，降级为 by construction）**：`open_soar` 的 loser 是**加噪 rollout**、与 winner 的 FM margin **天生巨大**，「学满分（reward_acc=1.0、margin 4–8）」近乎**定义性（by construction）**。它**只说明**：在**与似然对齐**的偏好下，**DPO-FM 机制可用、optimizer 正常**（同一个 `L_FM` 能稳定训练、margin 拉得开）。它**既不**构成「open-SOAR 音质更好」的独立证据，**也不**独立证明「`L_FM` 是**忠实**的似然代理」。

> 🔑 **`L_FM` 非退化（H2 被否）的真凭据前置在反相关本身、而非 open-SOAR 饱和（C2）**：「`L_FM` 不是无信息的重建难度」之判据，是**结构化、显著的反相关本身**——Spearman **−0.216**（settings-matched）/ 配对 setting_gap≡0（原偏相关 −0.392），叠加 per-component **三轴方向一致**（(−WER) / SIM / UTMOS 全负，§3.5）。一个退化（无信息）的 `L_FM` **给不出**这种结构化、跨轴一致的显著反相关。open-SOAR 训到饱和只因 **clean-vs-加噪 loser 极易分**（by construction），**不能反推** `L_FM` 的似然忠实度。

> 📎 **保留 heuristic-非-NLL caveat（C2 + 审稿 G）**：`L_FM` 仍只是**似然启发代理**、**非忠实 NLL 上界**（§1.1 措辞校正）；本节论点（L1 机制可用 + `L_FM` 非退化）**不**升级为「`L_FM` = 忠实 likelihood」。**独立锚实验 X14（typicality）已跑、结论 inconclusive**：配对比较 real 录音 vs reward-winner 的 `L_FM`——diff=winner−real=**+0.0007**（95%CI[−0.0020,+0.0032]、Wilcoxon p=0.69、**不显著**，n=188；real 0.7769 ≈ winner 0.7776）。真实录音**既不**系统更典型（不确认 L_FM 有效）、**也不**系统 atypical（不证伪）。故按可证伪线**保留 heuristic / 非忠实 NLL caveat、C2 不关**（现有据可依、非仅"待做"）；但**亦未证伪 C6**——real 非系统 atypical ⇒ 无证据 `L_FM` 退化/反似然，C6 两层切分不回退。`L_FM` 有效性仍由 **open-SOAR 饱和 + 结构化显著反相关本身**背书（而非独立 typicality 锚）。ODE-NLL 子协议(a)（8 接缝〔需核实〕）因 typicality null 提示无大 gap、性价比低，**不投入**。「open-SOAR 是否产出**更好的 held-out 音质**」仍是**另一回事**，由 **Table 1（held-out WER/SIM/UTMOS，§9 已落地）**裁决，不能由训练动力学断言。

> 注：`open_soar` 当前 `lambda_sft = 0.2`（带 clean-FM anchor）；RQ4 纯净版拟回 `0.0`，与此 by-construction 对照无关。

## 5. 它解释了整个调参史

这一**偏好-似然反向（L2）**是 B-15 / B-16 两类训练故障的**共同病根**（详见 [`05-踩坑与修复记录.md`](05-踩坑与修复记录.md) **B-15 / B-16**）：

- **欠拟合（margin → 0）**：DPO 想压低 winner 的 `L_FM`，但偏好对 winner/loser **平均无系统信号**（全量均值 ≈ 0、win_rate 0.53，大半是 near-tie 产物）→ 没有可供 DPO 稳定拉开的 margin 信号，且在质量差最大的 pair 上偏好还**反着似然**（反相关）→ 学不动，`reward_margin` 塌到 ~0.01、`dpo = ln2`。对应 B-16 的 run1。
- **过拟合（早期弱 anchor）**：在不锚住声学的弱 anchor 下，DPO 唯一能「赢」off-manifold 偏好的办法是**全局扭曲 FM 头** → 退化崩坏（`reward_acc=1.0` 是欺骗性的）。对应 B-15。

两症状（over-optimization ↔ under-fitting）看似相反，实为**同一病根**：当被偏好方向**不顺着**似然方向时（平均无信号叠加弱单调反相关），弱 anchor 走向退化、强 anchor 走向冻结，中间几乎没有可学的稳定窗口。B-16 当时把它收敛为「数据质量差是 margin 的硬上限」——本探针进一步揭示，**即便 reward 差充足（中位 1.39），FM margin 平均仍 ≈ 0 且与 reward 差弱单调反相关**，瓶颈不只在数据，更在**「best-vs-worst 偏好与模型似然反向」这一 L2 对齐失败本身**。

### 7.2 构想的建设性方向（非 likelihood-DPO）

按新论点，正确的两类路是 **(a) 偏好与似然对齐**（open-SOAR），**或 (b) 非似然目标**：

> 📎 per-component 强化（§3.5）：reward 三分量换到 reward-对齐方向后**三轴全部与 FM margin 负相关**（(−WER) −0.41 / SIM −0.68 / UTMOS −0.60）——**不是「只是 FM-vs-WER」**，每个 perceptual 轴的「更好」都更 off-manifold。故结论从「只修 reward 组成（换分量 / 换权重）」**强化为「整体弃 FM-as-reward」**：换分量都救不了，须改用非似然目标或似然对齐偏好。

- 在 winners 上做 **reward-weighted regression**；
- 经**可微 vocoder** 的直接 reward 反传；
- 用**学习式 value / preference 头**取代「`L_FM` 当 logprob」。

- **预测①（dpo_multiobj 主动退化）**：reward-based `dpo_multiobj` 相对 `base` **主动退化**（非仅欠拟合 ≈ base）。→ **证实**：`dpo_multiobj` WER **0.752 [0.566,1.035]** 与 base **0.103 [0.071,0.142]** CI **不重叠**，且叠加 **25% 生成失败**（见 §9.7）。但该 25% 究属 graded 退化还是 optimization divergence **证据不一、暂不定论**（保守报告为「生成时子集崩」，见 §9.7 / caveat 2）。
- **预测②（sft/open_soar escape）**：`sft`、`open_soar` 绕开 L2 坑、是建设性臂。→ **部分证伪**：`open_soar` **证实**（唯一改善），但 **`sft` 证伪**——它**也崩坏**（见 §9.3 反转）。按预承诺撤回规则，**撤回「sft 是建设性 escape 臂」**，建设性结论从「sft & open_soar 都安全」**收窄为「只有 open_soar 安全」**。
- **预测③（损害 ∝ pair 纯度）**：原想用 multiobj(0% 平局) vs weronly(63% 平局) 验「越干净伤越重」。→ **不能干净裁决**：审稿 P2 早已指出此对比混淆了 reward 定义与纯度；且 sft 崩坏给出了一个**更强、更出乎意料**的排序（见 §9.4），纯度-scaling 让位于「self-training 目标分布」这条主线。

### 9.3 重磅反转：**sft 也崩**——「sft 是安全建设性臂」被推翻

- n=3 冒烟里 `sft` 看着**最好**（WER 0.039），全量 n=100 **灾难崩坏**（WER **0.545**、SIM **0.673**、UTMOS 3.917）。
- 原因正是冒烟取样偏差：冒烟 3 句**全是 `LJ001` 前缀**、**错过崩坏块**（失败集中在 `LJ002` 块，见 caveat 3）。
- 审稿 R3 曾**钦点 `sft` 作「真正不受影响的决定性对照」**（见 [`07-审稿意见-第一轮.md`](07-审稿意见-第一轮.md) 必查项 3）——结果这个对照给出了**比原假设更强的发现**：连「不做 win/lose `L_FM` 对比」的纯监督臂都崩，说明病根**比 DPO-FM 错配更深**（见 §9.5 新论点）。
- 这直接修正 §7.1：**`sft` 不再是「绕开 L2 的建设性臂」**；§7.1 的「`sft` 绕开」表述须降级为「`sft` 同样崩坏，唯 `open_soar` 安全」。

### 9.4 单调崩坏序：按「往 reward 选出的自生成 winner 拉多狠」排序

把四臂按「训练目标把模型往**automatic-reward 选出的自生成 winner**拉的强度」排序，崩坏**单调加剧**：

| 拉向目标 | 臂 | 拉力强度 | 结果 |
|---|---|---|---|
| **真实 clean 音频**（非 reward-winner） | `open_soar` | clean-vs-perturbed，似然对齐 | **改善**（UTMOS 4.408 最佳） |
| reward-winner（弱、WER-only、63% 平局） | `dpo_weronly` | 弱拉 | **≈base**（WER 0.115 守住） |
| reward-winner（强监督） | `sft` | 强拉（直接 FM 监督向 winner） | **崩**（WER 0.545） |
| 最干净 reward-winner（DPO 强拉） | `dpo_multiobj` | 最强拉 + 反向梯度 | **灾难 + 25% 生成时子集崩** |

**共同线索**：automatic-reward 的 best-vs-worst 在 **guidance×num_steps×speaker_scale 多样池**上选出的 winner 是 **off-manifold**（清晰但不典型的高-guidance 样本）；把模型往这些**自生成 off-manifold winner** 做 self-train——**不管是 SFT 还是 DPO**——都退化，且**拉得越狠越惨**。唯独 `open_soar` 训向**真实 on-manifold** 目标（clean 音频），改善。

### 9.5 新论点：**off-manifold self-training 退化，与训练目标无关**

失败**不止**「DPO-FM 错配」或「DPO 的偏好-似然对齐」——n=100 揭示更深一层：

> **向 automatic-reward 选出的自生成候选（off-manifold）做 self-training，会退化模型，与训练目标（SFT/DPO）无关**；唯有训向真实 / 似然对齐的目标（`open_soar`）才有效。

证据：`sft`（纯监督、**不做** win/lose `L_FM` 对比、按 §7.1 旧逻辑「不踩 L2 坑」）**仍崩**——若病根只是「DPO 把偏好往反似然方向拉」，`sft` 不该崩。它崩了，说明真正的毒源是**目标分布本身（off-manifold winner）**，而非 DPO 的对比机制。据此建设性结论**收窄**：从「`sft` & `open_soar` 都安全」→「**只有 `open_soar` 安全；`sft` 同样崩**」。

> ⚠️ 严守 caveat：此论点**更强、更出乎意料**，但须如实标注混淆（见 §9.8 caveat 1）——`sft` 崩坏与「小数据 SFT 过拟合/灾难性遗忘」**尚未干净分离**，`open_soar` 不崩仅是**部分对照**。论点目前为**强假设**，须 SFT-on-random vs SFT-on-reward-winners 对照（future work）才能坐实。

### 9.6 RQ3 reward-hacking：诚实改为「**未复现**」

- `dpo_weronly` WER **0.115 ≈ base 0.103**（**不是最低**）、UTMOS 4.112 **略低于** base 4.309——WER-only 臂**没 hack 成**：DPO-FM 已坏，它也无法把 WER 压到最低。
- 这正是审稿预言的 **Contribution-2-vs-4 冲突**（[`07`](07-审稿意见-第一轮.md) R2）：若 DPO 臂崩坏，reward-composition 效应无法干净分离。
- 据此，PAPER **§5.3 / §6.4 须诚实改写**为：「**reward-hacking 在错配的 DPO-FM 框架内无法干净复现**——WER-only 臂未取得最低 WER，两个 DPO 臂都退化；reward-composition 效应被 FM 崩坏混淆，无法分离」，并把**贡献 4 降为该负面结论**。EmergentTTS 列仍空（未跑），不据此谈 naturalness。

### 9.7 §6.7 「active-degradation」预测裁决

审稿 / DA 要的解盲前预承诺——**`dpo_multiobj` 是否相对 base active degrade（而非仅 under-fit ≈ base）？**

> **裁决：是（active degradation 证实）。** `dpo_multiobj` WER CI **[0.566, 1.035]** 与 base **[0.071, 0.142]** **不重叠**，叠加 **25% 生成失败**（immediate-EOS/no-payload）→ PAPER §6.7 的 active-degradation 预测**证实**。
> ⚠️ **但含「生成时崩」成分（caveat 2）**：25% 失败是 immediate-EOS / no-payload 的**生成时子集崩**，与 graded（Spearman −0.216 的弱单调）**不同质**——崩坏量级**超出**弱单调相关的预测。**但「graded 退化 vs optimization divergence」证据不一、暂不定论**（X2/X3 已回填 [`08`](08-实验结果-Table1.md) §2/§4）：训练曲线 `fm_w` **全程稳 ~0.74、末段/早段 1.01×、未二次爆、reward-margin 仍小 0.065 → 训练未发散**（非 run0 式训练时爆炸）；交叉表大-gap 对 FM-reward 更脱钩（同向率 **34% vs 48%**）→ 偏 divergence；**合判 = 训练温和但模型已 off-manifold 漂移 → 部分 prompt（LJ002 子集）生成时崩**。故**既不可纯归因 graded 反相关、亦不可径直断言 optimization divergence**，须保守报告为「生成时子集崩」，待人工 TB-curve 复核 + 失败句听测裁决。这反过来**强化 off-manifold 论点**：错向梯度**不靠炸训练指标**（`fm_w` 未再爆、margin 仍小），而是悄悄把模型推离流形。

### 9.8 五条 caveat（务必如实，写进 §5/§6/§7 与 doc 08）

1. **sft 崩坏与「小数据 SFT 过拟合 / 灾难性遗忘」混淆**：188 单说话人 SFT 本就易过拟合/遗忘；干净判别需 **SFT-on-random-candidates vs SFT-on-reward-winners** 对照（future work）。`open_soar`（同规模微调、同优化器族）不崩是**部分对照**，指向「**目标分布（off-manifold winner）**」而非单纯「SFT 不稳」。
2. **dpo_multiobj 的 25% 失败是 immediate-EOS / no-payload 的「生成时子集崩」**，与 graded（Spearman −0.216）**不同质**；崩坏量级超出弱单调相关的预测。但**「graded vs optimization divergence」证据不一、暂不定论**（X2/X3 实测，见 [`08`](08-实验结果-Table1.md) §2/§4/caveat 2）：训练曲线 `fm_w` 全程稳 ~0.74、**未二次爆**、margin 仍小 0.065 → **训练未发散**（非 run0 式训练时爆炸）；交叉表大-gap 对 FM-reward 更脱钩（同向率 **34% vs 48%**）→ **偏 divergence**；**合判 = 训练温和但模型已 off-manifold 漂移 → 部分 prompt 生成时崩**。**保守报告，不径直断言 optimization divergence**，待人工 TB-curve + 失败句听测裁决。这**强化 off-manifold 论点**：错向梯度不靠炸训练指标（`fm_w` 未再爆、margin 仍小），而是悄悄把模型推离流形。
3. **失败聚于 `LJ002` 块**（`sft`、`dpo_multiobj` 皆然）须**诚实归因**：评测集（`eval_big` 取前 100 held-out）**本身 89% 为 LJ002**（89/100），故「聚于 LJ002」**部分因 LJ002 占评测主体**；组内 **LJ001 0/11（0%）vs LJ002 25/89（28%）**（小 n、p≈0.02）仍是真实 prompt 依赖、**非均匀**，失败样本仅**轻微偏长（text 105 vs 94 = 1.12×）、无位置偏置（后段 52%）**——**不写成「长 prompt 触发」**。仍**须专项排查**（prompt 内容 / 评测集排序 / fid 块边界）；这也正是 n=3 冒烟（全 `LJ001`）漏掉崩坏的原因。
4. **崩坏臂 CI 极大**（`sft` WER **[0.25, 1.06]**）、**单说话人 LJSpeech**、**无人类听测**——量级**仅供方向**，不可当精确效应。
5. **dpo_multiobj 主表 WER 0.752 只统计成功的 75 条**（失败的更差），故**失败率（25%）必须与 WER 并列**报告，否则低估崩坏。

### 9.9 机理闭环（更新：off-manifold → 训练侧 → 生成侧已闭合，新增 self-training 主线）

> **机理（§3，off-manifold 反相关 Spearman −0.216）→ 训练侧（§4.2，`open_soar` by-construction 学满分 / `dpo_multiobj` 学不动 + `fm_w` 0.5→1.0 预警）→ 生成侧（本节 n=100 实测：`dpo_multiobj` 灾难崩坏 + 25% 生成失败（生成时子集崩，graded-vs-divergence 证据不一）/ `sft` 也崩 / 唯 `open_soar` 改善）**。

- 前两级线索在 n=100 上**闭合**：训练侧 `fm_w` 0.5→1.0 的预警，在生成侧兑现为 `dpo_multiobj` 的灾难崩坏。
- 但生成侧带来**超出原机理**的一笔——**`sft` 也崩**，把诊断从「DPO-FM 偏好-似然反向」推进到「**off-manifold self-training 退化（与目标无关）**」（§9.5）。
- 唯一守住「训向真实 on-manifold 目标」的 `open_soar` 改善，反过来**正向印证**了这条主线。
