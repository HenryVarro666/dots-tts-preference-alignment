# 06 · 核心发现：FM 训练损失与 perceptual reward 反相关 —— DPO-FM 隐式奖励错配

> 本文是整个项目的**中心发现文档**，可被论文直接引用。所有数字均由探针 `alignment/probe_fm_reward.py` 在**全量 N=188** 个 best_worst pair 上实测得出（`--n 188 --k 16`），**逐字精确**、未经改动。n=24 仅作 pilot 留存对比。
> 关联：调参全过程见 [`05-踩坑与修复记录.md`](05-踩坑与修复记录.md) **B-15 / B-16**；方法假设见 [`01-METHOD.md`](01-METHOD.md)、[`02-DECISIONS.md`](02-DECISIONS.md)。

## TL;DR（一句话结论）

**在全量 N=188 个 best_worst pair 上，dots.tts 的 flow-matching 训练损失 `L_FM` 对 winner 没有系统偏好（44% 的 pair 为正、平均 win_rate 0.47 ≈ 抛硬币 0.5、margin 均值 −0.0071），但 FM margin 与 perceptual reward（WER / SIM / UTMOS 聚合）差显著反相关——Pearson ρ = −0.411（p ≈ 1e-8）、Spearman −0.187（p ≈ 0.01），两者均显著。** 头条是这条**稳健的 anti-correlation**：FM 对随机 winner/loser 平均无信号，且在**质量差最大**的 pair 上反而**最不**偏好 winner（指错方向）。

> *On the full N=188 set, the denoised FM margin shows no systematic preference for winners (44% positive, mean win-rate 0.47) yet is significantly anti-correlated with the reward gap (Pearson −0.411, p<1e-7; Spearman −0.187, p≈0.01); the pilot n=24 over-stated an average winner-dispreference that regressed to chance at scale, while the anti-correlation held and gained significance.*

这直接证伪了 DPO-FM 的核心前提（「把 `L_FM` 当隐式 log-likelihood 代理、winner 应有更低 `L_FM`」）：FM 既不偏好 winner（解释 `reward_margin` 长期塌在 ~0.01 的**欠拟合**），又与 reward 反相关（在质量差最大处指错方向）。这两点与早期弱 anchor 下的全局退化崩坏（过拟合）是**同一病根**——优化目标在与模型自身似然的几何对着干。

> 🔧 自我修正（pilot → 全量）：n=24 pilot 曾表观更强（4/24=17% 为正、win_rate 0.33、Pearson −0.496、Spearman −0.302），据此一度写下「winner 系统性 FM 更差」。全量 N=188 修正：win_rate 0.33→0.47（≈随机）、为正占比 17%→44%——pilot 的「winner 系统性更差」是**小样本 / 高杠杆点高估**，全量证伪。但**反相关稳健且更显著**（n=24 时 Spearman 不显著；N=188 下 Pearson 与 Spearman 双双显著，临界 \|r\|≈0.143）。故头条改用稳健的 anti-correlation，不再以「winner 系统性更差 / win_rate 0.33」为主结论。

> ✅ 边界（已关闭）：本反相关**究竟是 FM 的本质，还是候选生成 guidance 的混淆**，已用 `candidates/inspect_guidance_confound.py` 排除——winner/loser 的生成设置（guidance_scale / num_steps / speaker_scale）统计上无系统差异、与 reward 差仅弱相关（\|Pearson\|≤0.12），故确认为 **flow-matching 损失的【内在】反相关（intrinsic misspecification）**，非候选生成产物（见 §6）。

## 1. 被检验的猜想（实验猜想 / 决策树）

### 1.1 被检验的前提

DPO-FM 把 flow-matching 训练损失 `L_FM` 当作隐式 log-likelihood 代理（这是 Diffusion-DPO 从离散扩散到**连续-latent**的直接改编）。其成立**前提**是：

> **`L_FM` 必须跟 perceptual reward 走** —— 被偏好（高 WER/SIM/UTMOS 聚合 reward）的候选，应当具有**更低**的 `L_FM`。

如果这个前提不成立，DPO-FM 用 `−L_FM` 当 log-likelihood 的整套推导就失去地基。

### 1.2 触发猜想的反常现象

训练时观测到：**`reward_margin` 长期 ~0.01**（偶尔才炸到 0.5–0.8），`dpo` 损失卡死在 `ln2 ≈ 0.693`，`fm_w ≈ fm_l`——DPO 完全没在「拉开偏好」。但与此同时 `inspect_gap.py` 已证明 `pairs_best_worst` 的 **reward 差是充足的**（0% 近似平局，中位数 1.39）。**reward 差充足，FM margin 却塌成 0** —— 矛盾收敛到一个问题：`L_FM` 到底跟不跟 perceptual reward 走？

### 1.3 三假设决策树

针对「reward_margin ~0.01」这一现象，提出三个互斥假设，并设计探针去判别落在哪个分支：

| 假设 | 命题 | 含义 | 可否修复 |
|---|---|---|---|
| **H1（噪声，可修）** | `L_FM` **跟** reward，但单次 `(x0,t)` 估计方差太大，真信号被噪声淹没 | 方差问题 | **可修**：训练时对 `L_FM` 做 MC 平均（每步多采 `x0,t`）/ 增大 lr / 加步数 |
| **H2（无信息）** | `L_FM` 只反映**重建难度**，与 perceptual 质量**无关**（相关≈0） | 方法的有效性边界 | DPO-FM 能偏好 winner 但不对齐 reward |
| **H3（反相关，根本性）** | `L_FM` 与 reward **反相关** —— 被偏好候选的 `L_FM` 反而**更高** | 隐式奖励**错配** | **不可修配方**：优化目标与模型似然对着干 |

```
观测: reward 差充足(中位 1.39) 但 reward_margin~0.01, dpo=ln2
        │
        ▼  问: 去噪后的 FM margin = L_FM^lose − L_FM^win 落在哪？
  ┌─────────────┬───────────────────┬────────────────────┐
  │ 稳定为正+正相关 │   ≈0 / 不相关         │   稳定为负 / 负相关     │
  │   = H1 噪声    │   = H2 无信息          │   = H3 反相关(错配)    │
  │  修法:MC平均   │  方法边界,改隐式代理     │  整个 DPO-FM 配方错配  │
  └─────────────┴───────────────────┴────────────────────┘
```

**本探针的全量 N=188 结论**：FM 对 winner **无系统偏好**（margin 均值 ≈ 0、win_rate ≈ 0.47，落在 H2「无信息」一侧），但 FM margin 与 reward 差**显著反相关**（H3 的反相关在相关性维度成立，Pearson −0.411 / Spearman −0.187 双显著）；**H1（噪声可修）证伪**（MC 平均未把信号救成正、反相关稳健）。⚠️ 注：n=24 pilot 曾表观落在「H3：winner 系统性更差」分支（win_rate 0.33、4/24 为正），此分支已被全量 N=188 证伪——见 §3。详见 §3（含 §3.4 显著性）。

## 2. 全量 N=188 探针 `alignment/probe_fm_reward.py`

### 2.1 设计

- **样本**：全量 `N=188` 个 `best_worst` pair（来自 `pairs/out/pairs_best_worst.jsonl`）。（早期 `n=24` 为 pilot，见 §3.4。）
- **MC 估计**：每对 winner / loser 各算 `K=16` 次 Monte-Carlo（不同的 `(x0,t)` 噪声 draw）平均的 `L_FM`。
- **公共噪声抵消**：**每个 draw 内 win/lose 共享同一 `(x0,t)`**（与 DPO 训练同款可比性），消去公共噪声，直接比较二者对同一噪声的重建难度。
- **纯测量**：`no_grad`，不训练；复用 `check_fm_loss` 的 `DotsPreprocessor` + `fork_rng` 机制隔离全局 RNG。

### 2.2 度量

- **去噪 FM margin**（per pair）= `MC_k[ L_FM^lose − L_FM^win ]`，**> 0 ⇒ winner 的 `L_FM` 更低（更优）**。
- **win_rate** = `K` 次 draw 中 winner 更优（`L_FM^win < L_FM^lose`）的占比。
- **相关性**：去噪 FM margin 与 reward 差（`reward_win − reward_lose`）的 **Pearson / Spearman**。
- **噪声量级**：单次（`k=0`）FM margin 在 `N` 个 pair 上的样本标准差，用来对照 MC 均值，区分「噪声淹没」与「真信号为负」。

### 2.3 复现命令

```bash
python alignment/probe_fm_reward.py --pairs pairs/out/pairs_best_worst.jsonl --n 188 --k 16
```

> 本机（macOS / 无 GPU / 权重未下载）只能语法检查；该探针在 GPU 机器（有 pairs + dots.tts-base 权重）上实测运行，结果见 §3。

## 3. 结果（全量 N=188）

### 3.1 汇总指标

| 指标 | 数值（N=188） | 解读 |
|---|---|---|
| 去噪 FM margin **为正**的 pair | **82/188（44%）** | winner 与 loser 几乎对半——FM **无系统偏好** |
| 去噪 FM margin **均值** | **−0.0071** | 平均 ≈ 0（winner 略高，但量级微小） |
| 平均 **win_rate** | **0.47** | winner 被偏好概率 ≈ **抛硬币 0.5** |
| **Pearson**(FM margin, reward 差) | **−0.411** | reward 差越大 → FM margin 越负（**显著**，p≈1e-8） |
| **Spearman**(FM margin, reward 差) | **−0.187** | 单调反相关，秩相关同号（**显著**，p≈0.01） |
| 单次 margin **标准差**（噪声量级） | **0.0892** | ≫ \|MC 均值\| 0.0071 |

### 3.2 H1（噪声）证伪；FM 平均无信号 + 显著反相关

- 单次 margin 标准差 **0.0892 ≫ \|MC 均值\| 0.0071** —— **单步信号确实高噪**（这解释了为何训练时 `reward_margin` 抖动剧烈）。
- 去噪后（K=16 MC 平均）的**平均信号 ≈ 0**（均值 −0.0071、82/188=44% 为正、win_rate 0.47）：FM 对随机 winner/loser **无系统偏好**（落在 H2「无信息」一侧），**而非** pilot 表观的「winner 系统性更差」。
- 但 FM margin 与 reward 差**显著反相关**（Pearson −0.411、Spearman −0.187，双显著）：在质量差最大的 pair 上 FM 最不偏好 winner。
- 故：**不是 H1 的「方差问题」**（MC 平均没把均值救成正、也没消掉反相关），证伪 H1；结论为 **FM 平均无信号 + 显著反相关**的错配，而非「winner 系统性 `L_FM` 更高」。

### 3.3 逐对佐证（来自 n=24 pilot，仅示意反相关方向）

> ⚠️ 下表逐对数值来自 **n=24 pilot**（非全量 N=188），仅示意「reward 差最大的 pair 上 FM 反而最负」这一**反相关方向**；勿据此读出全量的平均偏好（全量 win_rate=0.47、均值 −0.0071，见 §3.1）。

| pair | reward_gap | 去噪 MC margin | win_rate | 说明 |
|---|---|---|---|---|
| **[4]** | **+2.839** | **−0.1604** | — | reward 最高的 winner，FM **最嫌弃**（margin 最负）——反相关的高杠杆点 |
| **[23]** | **+2.758** | — | **0.08** | 该 pair 24 次 draw 中 winner 仅 8% 更优 |
| **[1]** | **+2.698** | **−0.0804** | — | reward 高、该 pair FM margin 为负 |
| [5] | +2.765 | **+0.0268** | — | 同 reward 区也有正例，提示并非「winner 一律更差」 |

pilot 的高 reward_gap pair 多落在负 margin（反相关方向）；但这类**高杠杆点**也正是 pilot 把平均偏好高估为「winner 系统性更差」的来源——全量 N=188 上平均偏好回归至随机（win_rate 0.47），仅**反相关**稳健留存。

### 3.4 统计显著性（全量 N=188；附 n=24 pilot 的诚实修正）

头条主张「FM 与 reward 差**显著反相关**」在全量 N=188 下**稳健且双显著**；pilot 的「winner 系统性更差」被全量修正为随机：

- **anti-correlation 双显著（头条）**：N=188 临界 `|r| ≈ 0.143`；**Pearson −0.411**（**p ≈ 1e-8**）与 **Spearman −0.187**（**p ≈ 0.01**）**双双显著**。对比 n=24 pilot——Pearson −0.496、Spearman −0.302（彼时 Spearman **不显著**）；全量下相关量级略降，但 Spearman **转为显著**，反相关**更可信**。
- **平均偏好回归至随机**：N=188 上 82/188=44% margin 为正、win_rate 0.47、均值 −0.0071——FM 对随机 winner/loser **无系统偏好**。pilot 的 4/24=17%、win_rate 0.33 是**小样本 / 高杠杆点高估**，全量证伪，**不再作主结论**。
- **诚实修正叙事**：n=24 → N=188 的唯一定性变化是「winner 系统性更差」消失（win_rate 0.33→0.47），而「反相关」不仅留存且更显著。故本文删除 / 软化「winner 系统性更差 / win_rate 0.33 / 4-of-24 / 20-of-24」这类被全量证伪的表述（仅作 pilot 留痕），头条采用稳健的 **ρ = −0.41（Pearson/Spearman 双显著，N=188）**。

## 4. 机理：`L_FM` 衡量 typicality 而非 perceptual 质量

### 4.1 typicality-vs-quality 的内在错配

`L_FM` 衡量的是「**模型 flow 头下的 typicality / 似然**」（音频在模型自然分布中有多「典型」），**不是 perceptual 质量**。而 perceptual reward（尤其 **WER**）由候选的**生成设置**驱动：

> 高 guidance → 吐字更清（WER / UTMOS 更好）→ 但把音频**推离模型自然分布** → `L_FM` **更高**。

于是 reward 差最大的候选，往往恰是似然偏低的候选——这是经典的 **likelihood-vs-quality 错配**。本工作在连续-latent TTS 上对它做了量化：FM 对随机 winner/loser **平均无偏好**（win_rate 0.47），但与 reward 差**显著反相关**（ρ = −0.41，Pearson/Spearman 双显著，N=188）。该错配是**内在**的（guidance-confound 已排除，见 §6），与上述 typicality 机理一致。

### 4.2 `open_soar` 活体对照（最干净的内部确证）

同一套 DPO-FM 机器、只换**偏好信号**，是否与 FM 似然同向决定了能否学动——这是「FM-reward 错配」最干净的内部对照：

| 臂 | 偏好信号 | 与 FM 似然的关系 | 训练表现 | 反推 margin |
|---|---|---|---|---|
| **`dpo_multiobj`** | perceptual reward（WER/SIM/UTMOS 聚合） | 与 FM **无信号 / 反相关**（本文 §3） | `dpo` 卡在 `ln2 = 0.69`、`reward_margin ≈ 0.01` → **学不动** | ≈ 0.01 |
| **`open_soar`** | clean vs perturbed（扰动音频天生 `L_FM` 更高） | 与 FM **同向** | 训练 loss **0.12–0.22 ≪ ln2**、`reward_acc = 1.0` → **学满分** | ≈ 4–8 |

**唯一差别 = 偏好是否与 FM 似然同向**；只有同向（`open_soar`）学得动，反向 / 无信号（`dpo_multiobj`）学不动。这与 §3 全量 N=188 的诊断完全自洽：FM 当隐式奖励，只有当偏好恰好顺着 FM 似然时才奏效——而 perceptual reward 并不顺着它。

> 注：`open_soar` 当前 `lambda_sft = 0.2`（带 clean-FM anchor）；RQ4 纯净版拟回 `0.0`，与此对照的结论无关——同向 vs 反向能否学动，不依赖 anchor 权重。

## 5. 它解释了整个调参史

这一错配是 B-15 / B-16 两类训练故障的**共同病根**（详见 [`05-踩坑与修复记录.md`](05-踩坑与修复记录.md) **B-15 / B-16**）：

- **欠拟合（margin → 0）**：DPO 想压低 winner 的 `L_FM`，但 FM 对 winner/loser **无系统偏好**（全量均值 ≈ 0、win_rate 0.47）→ 没有可供 DPO 稳定拉开的 margin 信号，且在质量差最大的 pair 上 FM 还**反着来**（反相关）→ 学不动，`reward_margin` 塌到 ~0.01、`dpo = ln2`。对应 B-16 的 run1，并由 §4.2 的 `open_soar` 对照反证（偏好同向即可学满分）。
- **过拟合（早期弱 anchor）**：在不锚住声学的弱 anchor 下，DPO 唯一能「赢」的办法是**全局扭曲 FM 头** → 退化崩坏（`reward_acc=1.0` 是欺骗性的）。对应 B-15。

两症状（over-optimization ↔ under-fitting）看似相反，实为**同一病根**：当被偏好方向**不顺着**似然方向时（这里是平均无信号叠加显著反相关），弱 anchor 走向退化、强 anchor 走向冻结，中间几乎没有可学的稳定窗口。B-16 当时把它收敛为「数据质量差是 margin 的硬上限」——本探针进一步揭示，**即便 reward 差充足（中位 1.39），FM margin 平均仍 ≈ 0（无系统偏好）且与 reward 差显著反相关**，瓶颈不只在数据，更在 `L_FM` 当隐式奖励这一**机制本身**。

## 6. Open question — **已关闭：guidance-confound 已排除**

**反相关是 flow-matching 的【本质】，还是候选生成 guidance 的【混淆】？已查清——是【本质/内在】。**

原先两种可能：

1. **本质反相关**：在 dots.tts 的 flow 头下，perceptual 质量与似然天然背离——则结论是「**换偏好机制**」（FM-loss 不能当隐式奖励）。
2. **guidance 混淆**：winner 系统性地用了**更高的 guidance**（因为高 guidance 提升 WER → 更可能被选为 winner），高 guidance 又抬高 `L_FM`——则反相关来自候选生成协议，结论是「**换候选生成**」。

### 6.1 探针 `candidates/inspect_guidance_confound.py` 实测（已关闭分叉）

纯元数据 join（`pairs_best_worst.jsonl` ↔ `candidates_index.jsonl`，**188 对、0 join 失败**），逐项检验 winner/loser 的生成设置是否系统性不同：

| 生成超参 | winner 均值 | loser 均值 | 差 | winner 更高 / 更低 / 相等 | Pearson(reward 差, 设置差) |
|---|---|---|---|---|---|
| **guidance_scale** | 1.114 | 1.093 | **+0.021** | 39% / 29% / 32% | **+0.108** |
| **num_steps** | 11.85 | 10.44 | **+1.42** | 51%（更高） | **+0.118** |
| **speaker_scale** | 1.371 | 1.339 | **+0.032** | — | **+0.108** |

**判定**：winner/loser 的生成设置**统计上无系统差异**、与 reward 差**仅弱相关**（所有 `|Pearson| ≤ 0.12`）。winner 并未系统性地用更高 guidance/steps/speaker_scale，可能性 2（guidance 混淆）**被排除**。

### 6.2 结论：内在错配（intrinsic misspecification）

> guidance-confound **排除** —— winner/loser 生成设置统计上不可区分（`|Pearson| ≤ 0.12`），故 FM-reward 反相关是 **flow-matching 损失的【内在】性质**，非候选生成产物。
>
> *The guidance confound is excluded (winner/loser generation settings are statistically indistinguishable, `|Pearson| ≤ 0.12`), so the anti-correlation is **intrinsic** to the FM loss.*

结论由原先的「强假设 / 待查 confound」**收紧为已确认的内在错配**：论文主张走向定为「**换偏好机制**」（FM-loss 不能当隐式奖励），而非「换候选生成」。

复现命令见 §8.1。

## 7. 对实验 / 论文的影响（重构方向，**据 §6 关闭收紧/定稿**）

> §6 的 guidance-confound 探针**已关闭**（混淆排除、确认为内在错配），本节结论据此**收紧/定稿**——不再是待证的强假设，而是基于「内在反相关」的定向重构。

**贡献定位转向**：从「一个能用的 DPO 配方」转为**机理性警示研究**——

> 把 DPO / Diffusion-DPO 直接搬到连续-latent TTS（用 FM-loss 当隐式奖励）是**错配**的，因为 FM 似然与 perceptual reward **反相关**；这解释了它的不稳定，并**警示不可照搬离散-token 的偏好配方**。

### 7.1 关键推论：哪些臂**不受**此错配影响

- **`open_soar`（reward-free，干净-vs-扰动轨迹）不受影响**：它的偏好建立在「**轨迹洁净度**」（干净轨迹 vs 人为扰动轨迹）而非外部 reward 上，且**与 FM 似然同向**，不依赖「`L_FM` 跟 reward 走」这一前提，**仍是有效臂**——已由 §4.2 活体对照证实（loss 0.12–0.22、reward_acc 1.0、反推 margin 4–8，学满分）。
- **`sft`（仅在 winners 上做监督 FM）不受影响**：它**不做 win/lose 的 `L_FM` 对比**，只是把模型拉向 winner（高质量）音频 → **不踩这个坑**，可能是真正起作用的**建设性臂**。

### 7.2 构想的建设性方向（非 FM-loss-DPO）

- 在 winners 上做 **reward-weighted regression**；
- 经**可微 vocoder** 的直接 reward 反传；
- 用**学习式 value / preference 头**取代「`L_FM` 当 logprob」。

## 9. 下游后果：DPO-FM 不止无效，而是主动崩坏（eval 冒烟 n=3，全量待补）

> 🔴 **n=3 冒烟边界（先读这条再看数）**：以下数字来自 **n=3** 的 eval 冒烟（`run_matrix --manifest eval_smoke(3句) --nfe 10 --skip-streaming`），**CI 巨大、数字噪声极大**，**仅用于确认评测管线端到端跑通 + 效应方向**，**绝不可读出精确量级、不可当定论、不可写进 PAPER 正文作结果**。精确量级与显著性以**全量 n=100** 为准（待用户更新后回填）。

§3 的机理（**ρ = −0.41 反相关**）与 §4.2 的训练侧活体对照（`open_soar` 学满分、`dpo_multiobj` 学不动）已构成两级证据；本节补上**生成侧**第三级——把 base + 4 臂真实合成后送评测，看错配在**最终音频**上的后果。

### 9.1 管线已端到端跑通

`base + 4臂 合成（DotsTtsRuntime.generate）→ WER（Whisper-v3）/ SIM（ecapa）/ UTMOS（utmos22_strong）→ aggregate → main_table` 全链路在 GPU 机器上**端到端跑通**（n=3、nfe=10、skip-streaming 的冒烟配置）。本节首先验证的是**评测管线本身可用**，其次才是下面的方向性读数。

### 9.2 五臂 n=3 小表（仅看方向，勿读量级）

| 臂 | WER | SIM | UTMOS | 方向（n=3，噪声极大，仅示意） |
|---|---|---|---|---|
| **base** | 0.076 | 0.85 | 4.41 | 基线 |
| **sft** | 0.039 | 0.87 | 4.09 | ← WER / SIM 改善 |
| **open_soar** | 0.077 | 0.82 | 4.49 | ← UTMOS 最佳（最自然） |
| **dpo_multiobj** | **0.88** | **0.38** | **2.43** | ← **彻底崩坏** |
| **dpo_weronly** | 0.24 | 0.82 | 4.00 | ← 轻度退化 |

（WER 越低越好；SIM / UTMOS 越高越好。CI 巨大，**只读相对方向，勿读精确量级**。）

### 9.3 机理闭环：错配 → 训练侧 → 生成侧

- **DPO-FM 不是「学不动 ≈ base」，而是主动把模型搞坏**：`dpo_multiobj` 的 WER 从 base **0.076 → 0.88**、SIM **0.85 → 0.38**、UTMOS **4.41 → 2.43**——这不是「停在原地」，而是被推进**退化区**。§3 的反相关隐式奖励梯度**指错方向**，600 步把策略一路推向退化。
- **训练侧早有预警**：`dpo_multiobj` 训练时 `fm_w` 从 base 的 **~0.5 涨到 ~1.0**（winner 的重建在**变差**）——生成侧崩坏在训练侧已留下指纹。
- **损害 ∝ pair 信号纯度**（本节最强的方向性证据）：
  - **`dpo_multiobj`** 的 pair 最干净（**0% 平局、reward 差最大**）→ 错向梯度**最强** → 崩最惨（**WER 0.88**）；
  - **`dpo_weronly`** 的 pair **63% 平局** → 信号弱 → 只**轻度退化**（**WER 0.24**）。
  - 「**越干净的偏好、错向时伤得越重**」——错向梯度的强弱可由 pair 纯度**单调预测**，这本身是「错配为因、非随机崩坏」的强证据。

### 9.4 对照：sft / open_soar 改善，不踩坑

- **`sft`**（仅在 winners 上做监督 FM，**不做 win/lose 的 `L_FM` 对比**）→ WER **0.076 → 0.039**、SIM **0.85 → 0.87** 改善（UTMOS 4.41 → 4.09 略降但不崩）。
- **`open_soar`**（同向偏好：干净 vs 扰动轨迹，**与 FM 似然同向**）→ UTMOS **4.49（五臂最佳、最自然）**，WER/SIM 与 base 基本持平。
- 二者都**绕开了「win/lose 的 `L_FM` 反向对比」这个坑**——与 §7.1 的预测（`sft` / `open_soar` 不受此错配影响）一致，生成侧**初步**印证了机理推断。

### 9.5 三级证据链

> **机理（§3，ρ = −0.41 反相关）→ 训练侧（§4.2，`open_soar` 学满分 / `dpo_multiobj` 学不动 + `fm_w` 0.5→1.0 预警）→ 生成侧（本节，`dpo_multiobj` 崩坏 WER 0.88、`sft`/`open_soar` 改善）** 三级自洽：FM 当隐式奖励的错配，不仅在**相关性**上可测、在**训练动力学**上可见，更在**最终音频**上酿成**主动崩坏**。

⚠️ **再次强调边界**：以上 n=3 数字仅锁定**管线通 + 效应方向**；**精确量级与显著性以全量 n=100 为准，待回填**。在此之前**不得**把任一具体数值当结论或写入 PAPER 正文。
