# 06 · 核心诊断：likelihood-surrogate 有效，但 preference-likelihood 失败 —— DPO-FM 在 dots.tts 上撞上已知的 likelihood-quality / CFG off-manifold gap

> 本文是本项目的**核心诊断文档**，可被论文直接引用。**定位**（已按第一轮审稿重述）：不是「首次发现 / 首次量化」某新现象，而是把一个**教科书级、已知**的 **likelihood-vs-quality / classifier-free-guidance off-manifold gap**（Theis et al. 2016；Ho & Salimans 2022；Gao et al. 2023），在**连续-latent flow-matching TTS（dots.tts）**这一新架构上做**领域量化**，并附上据我们所知该架构的**首个 DPO 实例（DPO-FM）+ open-SOAR**。

## TL;DR（两层结论：似然代理**有效**，偏好-似然对齐**失败**）

诊断必须分两层，**不要把它们混成一句「L_FM 错配」**：

| 层 | 命题 | 本工作的结论 |
|---|---|---|
| **L1 · likelihood-surrogate validity** | `L_FM` 是否是有效的隐式 log-likelihood 代理？ | **完好。** 同一套 DPO-FM 机器、同一个 `L_FM`，只要偏好**与似然对齐**（open-SOAR：clean vs perturbed rollout）就**学得动**（训练侧 `reward_acc=1.0`、margin 4–8——**by construction**，见 §4.2）。这证明 `L_FM` 本身不是坏代理。 |
| **L2 · preference-likelihood alignment** | best-vs-worst 选出的偏好，是否与模型自身 flow 似然同向？ | **真失败在这一层。** automatic-metric reward（WER/SIM/UTMOS 聚合）在 **guidance×num_steps×speaker_scale 多样候选池**上 best-vs-worst 选出的偏好，与模型 flow 似然**反向**——这是经典 **likelihood-vs-quality / CFG off-manifold** gap，本文在连续-latent TTS 上量化之。 |

**头条统计（领稳健量 Spearman）**：在全量 N=188 上，去噪 FM margin 与 automatic-metric reward 差 **Spearman ρ = −0.187（ρ² ≈ 3.5%，按 Cohen 属弱单调反相关；p ≈ 0.01）** —— 这是**稳健头条**；**Pearson −0.411（p ≈ 1e-8）**并列标注为「**少数高杠杆点放大的线性系数**」（Pearson/Spearman ≈ 2.2，故领秩相关）。同时 FM margin 对随机 winner/loser **平均无系统偏好**（82/188 = 44% 为正、win_rate 0.47；binomial 双侧 p ≈ 0.08——**与 0.5 无显著差异、仅 trending below 0.5**，**不写** at chance / 抛硬币）。

> *On the full N=188 set the denoised FM margin is **weakly but significantly monotonically anti-correlated** with the automatic-metric reward gap (Spearman ρ=−0.187, ρ²≈3.5%, p≈0.01 — the robust headline; Pearson −0.411, p<1e-7, reported alongside as a leverage-amplified linear coefficient). On average it shows no systematic winner-preference (positive on 82/188=44% of pairs, mean win-rate 0.47; binomial two-sided p≈0.08 — not significantly different from 0.5, trending below it). This is a domain quantification of the known likelihood-vs-quality / CFG off-manifold gap, not a defect of L_FM itself: open-SOAR trains to saturation with the same L_FM under a likelihood-aligned preference.*

**新论点（一句话）**：**likelihood-based DPO 在 reward 偏好具有 off-manifold 属性时是错的工具。** 正确的路是 **(a) 用与似然对齐的偏好**（open-SOAR）**，或 (b) 改用非似然目标**——winners 上的 reward-weighted regression / 经可微 vocoder 直接 reward 反传 / 学习式 value(preference) 头。这同时解释了 DPO-FM 的欠拟合（margin→0）与早期弱 anchor 下的退化崩坏（见 §5）。

> 🔧 自我修正（pilot → 全量，论文最大诚信资产）：n=24 pilot 曾表观更强（4/24 = 17% 为正、win_rate 0.33、Pearson −0.496、Spearman −0.302），据此一度写下「winner 系统性 FM 更差」。全量 N=188 修正：win_rate 0.33→0.47、为正占比 17%→44%——pilot 的「winner 系统性更差」是**小样本 / 高杠杆点高估**，全量证伪。但**反相关稳健且更显著**（n=24 时 Spearman 不显著；N=188 下 Pearson 与 Spearman 双双显著，临界 \|r\| ≈ 0.143）。故头条改用稳健的 **Spearman 反相关**，不再以「winner 系统性更差 / win_rate 0.33」为主结论。

> ⚠️ 边界（**未关闭，待偏相关裁决**）：本反相关**究竟在控住生成设置后仍存活（→ 与 `L_FM` 几何绑定），还是部分由候选生成 guidance 驱动**，**尚未裁决**。已跑的 `candidates/inspect_guidance_confound.py` 在 N=188 上**未检出**单一生成设置的显著混淆，但**测错了量**（测的是 `corr(reward-gap, setting-gap)`，该测 `corr(FM-margin, setting-gap)`），且三个 setting-gap 相关 **+0.108 / +0.118 / +0.108 均为预测方向、CI 上界达 +0.26**（约为临界 0.143 的 75–82%）——**under-powered，不能接受零假设当等价**。决定性的**偏相关** `corr(FM-margin, reward-gap | guidance, num_steps, speaker_scale)` 由 `alignment/probe_analysis.py` 给出，**结论待该结果**。在此之前**不得**声称「intrinsic / confound excluded」（见 §6）。

## 1. 被检验的猜想（实验猜想 / 决策树）

### 1.1 被检验的前提

DPO-FM 把 flow-matching 训练损失 `L_FM` 当作隐式 log-likelihood 代理（这是 Diffusion-DPO 从图像扩散到**连续-latent flow-matching**的直接改编）。其**前提**是：

> **被偏好（automatic-metric reward 更高：WER/SIM/UTMOS 聚合）的候选，应当具有更低的 `L_FM`** —— 即偏好方向**与模型 flow 似然同向**。

注意这条前提里**两件事被绑在一起**：(i) `L_FM` 是有效似然代理（L1）；(ii) 偏好与该似然同向（L2）。本工作发现 **(i) 成立、(ii) 不成立**——失败在**偏好与似然的对齐**，而非 `L_FM` 这个代理本身。

> 📎 措辞校正（审稿 G）：`L_FM` = flow-matching velocity-MSE。把它当 `−log p` 的**变分上界**是**过强**的说法——在 conditional flow-matching（CFM, Lipman et al. 2023）下，它是**向量场 MSE 的无偏估计**，把它读作 likelihood 代理是 Diffusion-DPO 的**启发式（heuristic）**继承、**非已证 NLL 界**。本文据此只把它当**有效的似然启发代理**，而非严格变分界。

### 1.2 触发猜想的反常现象

训练时观测到：**`reward_margin` 长期 ~0.01**（偶尔才炸到 0.5–0.8），`dpo` 损失卡死在 `ln2 ≈ 0.693`，`fm_w ≈ fm_l`——DPO 完全没在「拉开偏好」。但与此同时 `inspect_gap.py` 已证明 `pairs_best_worst` 的 **reward 差是充足的**（0% 近似平局，中位数 1.39）。**reward 差充足，FM margin 却塌成 0** —— 矛盾收敛到一个问题：best-vs-worst 选出的偏好，到底跟不跟模型 flow 似然走？

### 1.3 三假设决策树

针对「reward_margin ~0.01」这一现象，提出三个互斥假设，并设计探针去判别落在哪个分支：

| 假设 | 命题 | 含义 | 修复路径 |
|---|---|---|---|
| **H1（噪声，可修）** | 偏好**跟**似然，但单次 `(x0,t)` 估计方差太大，真信号被噪声淹没 | 方差问题 | **可修**：训练时对 `L_FM` 做 MC 平均 / 增大 lr / 加步数 |
| **H2（无信息）** | FM margin 只反映**重建难度**，与 automatic-metric 质量**无关**（相关≈0） | 偏好与似然**无关** | 改隐式代理 / 换非似然目标 |
| **H3（反相关）** | FM margin 与 reward **反相关** —— 被偏好候选**更不典型(off-manifold)**、`L_FM` 反而**更高** | **偏好-似然对齐失败**（L2），即 likelihood-quality / CFG off-manifold gap | **换偏好信号**（似然对齐，如 open-SOAR）**或换非似然目标** |

```
观测: reward 差充足(中位 1.39) 但 reward_margin~0.01, dpo=ln2
        │
        ▼  问: 去噪后的 FM margin = L_FM^lose − L_FM^win 落在哪？
  ┌─────────────┬───────────────────┬──────────────────────────┐
  │ 稳定为正+正相关 │   ≈0 / 不相关         │   ≈0 但与 reward 显著反相关      │
  │   = H1 噪声    │   = H2 无信息          │   = H3 偏好-似然反向(off-manifold) │
  │  修法:MC平均   │  换隐式代理/非似然目标    │  换偏好信号(似然对齐) 或 非似然目标  │
  └─────────────┴───────────────────┴──────────────────────────┘
```

**本探针的全量 N=188 结论**：FM 对随机 winner/loser **平均无系统偏好**（margin 均值 ≈ 0、win_rate ≈ 0.47，落在 H2 一侧），但 FM margin 与 reward 差**显著反相关**（H3 的反相关成立，Spearman −0.187 弱单调显著、Pearson −0.411 显著）；**H1（噪声可修）证伪**（MC 平均未把信号救成正、反相关稳健）。结论：失败在 **L2（偏好-似然反向）**，不是 `L_FM`（L1）坏。⚠️ n=24 pilot 曾表观落在「H3：winner 系统性更差」分支（win_rate 0.33、4/24 为正），此分支已被全量 N=188 证伪——见 §3。

## 2. 全量 N=188 探针 `alignment/probe_fm_reward.py`

### 2.1 设计

- **样本**：全量 `N=188` 个 `best_worst` pair（来自 `pairs/out/pairs_best_worst.jsonl`）。（早期 `n=24` 为 pilot，见 §3.4。）
- **MC 估计**：每对 winner / loser 各算 `K=16` 次 Monte-Carlo（不同的 `(x0,t)` 噪声 draw）平均的 `L_FM`。
- **公共噪声抵消**：**每个 draw 内 win/lose 共享同一 `(x0,t)`**（与 DPO 训练同款可比性），消去公共噪声，直接比较二者对同一噪声的重建难度。
- **纯测量**：`no_grad`，不训练；复用 `check_fm_loss` 的 `DotsPreprocessor` + `fork_rng` 机制隔离全局 RNG。
- **落盘**（新增，供 `probe_analysis.py` 复用）：逐对 `fid / reward_gap / mc_margin / win_rate / win_audio / lose_audio` 写 `alignment/out/probe_per_pair.csv`，使统计加固（偏相关/杠杆/per-component）可在 CPU 上秒级反复跑。

### 2.2 度量

- **去噪 FM margin**（per pair）= `MC_k[ L_FM^lose − L_FM^win ]`，**> 0 ⇒ winner 的 `L_FM` 更低（更优）**。
- **win_rate** = `K` 次 draw 中 winner 更优（`L_FM^win < L_FM^lose`）的占比。
- **相关性**：去噪 FM margin 与 **automatic-metric reward** 差（`reward_win − reward_lose`）的 **Spearman（头条）/ Pearson**。
- **噪声量级**：单次（`k=0`）FM margin 在 `N` 个 pair 上的样本标准差，用来对照 MC 均值，区分「噪声淹没」与「真信号为负」。

> 📎 措辞校正（审稿 G）：reward 为 16 kHz 上算的 WER+SIM+UTMOS 自动指标聚合、**无人类听测**，dots.tts 的 48 kHz 优势对它不可见。故全文称 **automatic-metric reward**，未做 ABX/MOS 前**不称** perceptual reward / naturalness。

### 2.3 复现命令

```bash
python alignment/probe_fm_reward.py --pairs pairs/out/pairs_best_worst.jsonl --n 188 --k 16
```

> 本机（macOS / 无 GPU / 权重未下载）只能语法检查；该探针在 GPU 机器（有 pairs + dots.tts-base 权重）上实测运行，结果见 §3。

## 3. 结果（全量 N=188）

### 3.1 汇总指标（头条领稳健 Spearman）

| 指标 | 数值（N=188） | 解读 |
|---|---|---|
| **Spearman**(FM margin, reward 差)（**头条**） | **−0.187**（ρ² ≈ 3.5%） | 弱单调反相关，**显著**（p≈0.01）；按 Cohen 属弱效应——**稳健头条** |
| **Pearson**(FM margin, reward 差)（并列） | **−0.411** | 线性系数，**显著**（p≈1e-8）；但 Pearson/Spearman ≈ 2.2 ⇒ **少数高杠杆点放大**，故不作头条 |
| 去噪 FM margin **为正**的 pair | **82/188（44%）** | winner 与 loser 几乎对半——FM **平均无系统偏好**（binomial 双侧 p≈0.08，与 0.5 无显著差、仅 trending below） |
| 去噪 FM margin **均值** | **−0.0071** | 平均 ≈ 0（winner 略高，但量级微小） |
| 平均 **win_rate** | **0.47** | winner 被偏好概率 ≈ 0.5（**不写** at chance；见 binomial 注） |
| 单次 margin **标准差**（噪声量级） | **0.0892** | ≫ \|MC 均值\| 0.0071 |

### 3.2 H1（噪声）证伪；FM 平均无信号 + 弱单调显著反相关

- 单次 margin 标准差 **0.0892 ≫ \|MC 均值\| 0.0071** —— **单步信号确实高噪**（这解释了为何训练时 `reward_margin` 抖动剧烈）。
- 去噪后（K=16 MC 平均）的**平均信号 ≈ 0**（均值 −0.0071、82/188=44% 为正、win_rate 0.47）：FM 对随机 winner/loser **无系统偏好**。binomial 检验 82/188 双侧 **p ≈ 0.08** —— 与 0.5 **无显著差异、仅略低**；据审稿 G **不写**「at chance / 抛硬币」。
- 但 FM margin 与 reward 差**显著反相关**：**Spearman −0.187（头条，弱单调，p≈0.01）**、Pearson −0.411（杠杆放大的线性系数，p≈1e-8）。
- 故：**不是 H1 的「方差问题」**（MC 平均没把均值救成正、也没消掉反相关），证伪 H1；结论为 **FM 平均无信号 + 弱单调显著反相关**——失败在偏好-似然对齐（L2），而非 `L_FM`（L1）。

> ⚠️ 证据权重（审稿 G）：「平均无偏好（win_rate 0.47）」**大半是 near-tie 数据产物**（多数 same-prompt pair 候选声学过近，见 §5），**不再作独立的 L2 失败证据**。核心证据是**反相关**，且需进一步在**高-gap（非平局）子集**上证明它**存活**（待 `probe_analysis.py` 的 trim / 偏相关 / per-component 输出）。

### 3.4 统计显著性（全量 N=188；附 n=24 pilot 的诚实修正）

头条主张「FM 与 reward 差**显著反相关（弱单调）**」在全量 N=188 下**稳健且双显著**；pilot 的「winner 系统性更差」被全量修正为随机：

- **anti-correlation 双显著（头条领 Spearman）**：N=188 临界 `|r| ≈ 0.143`；**Spearman −0.187（头条，p ≈ 0.01）**与 **Pearson −0.411（p ≈ 1e-8）双双显著**。对比 n=24 pilot——Pearson −0.496、Spearman −0.302（彼时 Spearman **不显著**）；全量下 Spearman **转为显著**，反相关**更可信**。**领 Spearman**（ρ²≈3.5%、Cohen 弱单调），Pearson 并列为「杠杆放大的线性系数」。
- **平均偏好回归至随机**：N=188 上 82/188=44% margin 为正、win_rate 0.47、均值 −0.0071——FM 对随机 winner/loser 无系统偏好（binomial p≈0.08）。pilot 的 4/24=17%、win_rate 0.33 是**小样本 / 高杠杆点高估**，全量证伪，**不再作主结论**。
- **诚实修正叙事**：n=24 → N=188 的唯一定性变化是「winner 系统性更差」消失（win_rate 0.33→0.47），而「反相关」不仅留存且更显著。故本文删除 / 软化「winner 系统性更差 / win_rate 0.33 / 4-of-24 / 20-of-24」这类被全量证伪的表述（仅作 pilot 留痕），头条采用稳健的 **Spearman ρ = −0.187（双显著，N=188；Pearson −0.411 并列）**。

> 📎 待补的统计加固（`alignment/probe_analysis.py`，CPU 秒级）：(1) 双系数 bootstrap 95% CI；(2) 删 top-5% \|reward_gap\| 后重算 Pearson + 留一法最大影响（杠杆诊断）；(3) **正确的 confound 测** `corr(FM-margin, setting-gap)`；(4) **偏相关** `corr(FM-margin, reward-gap | 设置)` + TOST（裁决 §6 的 intrinsic 存亡）；(5) per-component `corr(FM-margin, WER/SIM/UTMOS gap)`；(6) distinct-prompt 计数（独立性）。结论以这些输出为准。

## 4. 机理：偏好选出的 winner 是**更不典型(off-manifold)**的成员

### 4.1 likelihood-vs-quality / CFG off-manifold gap（已知现象的领域量化）

`L_FM` 衡量的是「**音频在模型 flow 头下的 typicality / 似然**」（有多「典型」），**不是 automatic-metric 质量**。在 **guidance×num_steps×speaker_scale 多样候选池**上、用质量奖励做 **best-vs-worst** 选出的 winner，往往是该 pair 里**内容上更不典型（off-manifold）**的成员（不论是哪个 knob 造成的）——于是模型 flow 似然对它**更低**，FM margin 为负。

> ⚠️ 机理校正（审稿 C1/D）：**不**把反相关归因到「winner 系统性用了更高 guidance」这一 knob 层面——`inspect_guidance_confound.py` 显示 winner/loser 的 guidance/steps/speaker_scale 统计无系统差异（§6），已作 per-pair 驱动**排除**。机理重述在**内容典型性**层面：质量奖励倾向选出**off-manifold（更不典型）**的候选作 winner，**不论**该不典型由哪个采样设置造成 → 模型 flow 似然更低。

这正是经典的 **likelihood-vs-quality 错配**（Theis et al. 2016：生成模型里似然 ≠ 感知质量）与 **classifier-free-guidance off-manifold** 现象（Ho & Salimans 2022：CFG 以**降低似然**换取**保真度**——更清晰的样本恰恰偏离模型自然分布），叠加 **reward over-optimization**（Gao et al. 2023）。本工作**不是发现**它，而是把它**在连续-latent flow-matching TTS（dots.tts）上量化**：FM 对随机 winner/loser 平均无偏好（win_rate 0.47），但与 reward 差**弱单调显著反相关**（Spearman −0.187；Pearson −0.411 并列，N=188）。

### 4.2 `open_soar` 训练侧对照（L1「似然代理有效」的 by-construction 印证）

同一套 DPO-FM 机器、只换**偏好信号**，是否与 FM 似然同向决定了能否学动：

| 臂 | 偏好信号 | 与 FM 似然的关系 | 训练表现 | 反推 margin |
|---|---|---|---|---|
| **`dpo_multiobj`** | automatic-metric reward（WER/SIM/UTMOS 聚合） | 与 FM **无信号 / 反相关**（§3，L2 失败） | `dpo` 卡在 `ln2 = 0.69`、`reward_margin ≈ 0.01` → **学不动** | ≈ 0.01 |
| **`open_soar`** | clean vs perturbed rollout（扰动音频天生 `L_FM` 更高） | 与 FM **同向** | 训练 loss **0.12–0.22 ≪ ln2**、`reward_acc = 1.0` → **学满分** | ≈ 4–8 |

**读法（审稿 G，降级为 by construction）**：`open_soar` 的 loser 是**加噪 rollout**、与 winner 的 FM margin **天生巨大**，「学满分（reward_acc=1.0、margin 4–8）」近乎**定义性（by construction）**，**不**构成「open-SOAR 音质更好」的独立证据。它**确证的是 L1**：在**与似然对齐**的偏好下，**同一个 `L_FM`** 就能稳定训练——故 `L_FM` 是**有效的似然代理**，DPO-FM 的失败不在代理本身。「open-SOAR 是否产出**更好的 held-out 音质**」是**另一回事**，须由 **Table 1（held-out WER/SIM/UTMOS，planned）**裁决，不能由训练动力学断言。

> 注：`open_soar` 当前 `lambda_sft = 0.2`（带 clean-FM anchor）；RQ4 纯净版拟回 `0.0`，与此 by-construction 对照无关。

## 5. 它解释了整个调参史

这一**偏好-似然反向（L2）**是 B-15 / B-16 两类训练故障的**共同病根**（详见 [`05-踩坑与修复记录.md`](05-踩坑与修复记录.md) **B-15 / B-16**）：

- **欠拟合（margin → 0）**：DPO 想压低 winner 的 `L_FM`，但偏好对 winner/loser **平均无系统信号**（全量均值 ≈ 0、win_rate 0.47，大半是 near-tie 产物）→ 没有可供 DPO 稳定拉开的 margin 信号，且在质量差最大的 pair 上偏好还**反着似然**（反相关）→ 学不动，`reward_margin` 塌到 ~0.01、`dpo = ln2`。对应 B-16 的 run1。
- **过拟合（早期弱 anchor）**：在不锚住声学的弱 anchor 下，DPO 唯一能「赢」off-manifold 偏好的办法是**全局扭曲 FM 头** → 退化崩坏（`reward_acc=1.0` 是欺骗性的）。对应 B-15。

两症状（over-optimization ↔ under-fitting）看似相反，实为**同一病根**：当被偏好方向**不顺着**似然方向时（平均无信号叠加弱单调反相关），弱 anchor 走向退化、强 anchor 走向冻结，中间几乎没有可学的稳定窗口。B-16 当时把它收敛为「数据质量差是 margin 的硬上限」——本探针进一步揭示，**即便 reward 差充足（中位 1.39），FM margin 平均仍 ≈ 0 且与 reward 差弱单调反相关**，瓶颈不只在数据，更在**「best-vs-worst 偏好与模型似然反向」这一 L2 对齐失败本身**。

## 6. 边界 — **未关闭：guidance-confound under-powered，待偏相关裁决**

**反相关在控住生成设置后是否仍存活（→ 与 `L_FM` 几何绑定），还是部分由候选生成 guidance 驱动？尚未裁决。** 据审稿 C1/C5，原先「已排除 → intrinsic」的结论**降级**为「**未检出，但 under-powered**」。

两种可能（仍并存）：

1. **与似然几何绑定**：在 dots.tts 的 flow 头下，automatic-metric 质量与似然天然背离——则结论是「**换偏好机制 / 换非似然目标**」。
2. **guidance 混淆**：winner 系统性地用了**更高 guidance**（高 guidance 提升 WER → 更可能被选为 winner），高 guidance 又抬高 `L_FM`——则反相关（部分）来自候选生成协议，结论是「**换候选生成（设置匹配配对）**」。

### 6.1 已跑：`candidates/inspect_guidance_confound.py`（**未检出**，但测错了量）

纯元数据 join（`pairs_best_worst.jsonl` ↔ `candidates_index.jsonl`，**188 对、0 join 失败**），逐项检验 winner/loser 的生成设置是否系统性不同：

| 生成超参 | winner 均值 | loser 均值 | 差 | winner 更高 / 更低 / 相等 | Pearson(reward 差, 设置差) |
|---|---|---|---|---|---|
| **guidance_scale** | 1.114 | 1.093 | **+0.021** | 39% / 29% / 32% | **+0.108** |
| **num_steps** | 11.85 | 10.44 | **+1.42** | 51%（更高） | **+0.118** |
| **speaker_scale** | 1.371 | 1.339 | **+0.032** | — | **+0.108** |

**判定（降级）**：winner/loser 的生成设置**未检出**系统差异，与 reward 差**仅弱相关**（所有 `|Pearson| ≤ 0.12`）。但**两点使「排除」站不住**：
- **测错了量（审稿 C1）**：上表测的是 `corr(reward-gap, setting-gap)`；要排除混淆，该测的是 **`corr(FM-margin, setting-gap)`**（混淆作用在 FM margin 上，不是在 reward 上）。
- **under-powered（审稿 C5）**：三个相关 **+0.108 / +0.118 / +0.108 全是预测方向**、约为临界 `0.143` 的 **75–82%**；其中 +0.118 的 bootstrap CI 上界可达 **+0.26**。在 N=188 下**接受零假设 ≠ 等价**，需 **TOST** 才能主张可忽略。

### 6.2 决定性裁决：偏相关（`alignment/probe_analysis.py`，**待结果**）

> **尚不能声称 intrinsic。** 唯一的决定性裁决是**偏相关** `corr(FM-margin, reward-gap | guidance, num_steps, speaker_scale)` + bootstrap CI + TOST，由 `alignment/probe_analysis.py` 给出（读 `probe_per_pair.csv` + join `candidates_index.jsonl`，CPU 秒级）：
> - **偏相关仍显著（CI 排除 0）** → 反相关在控住生成设置后存活 → 与 `L_FM` 几何绑定，论文主张「换偏好机制 / 非似然目标」；
> - **偏相关塌到不显著 / TOST 通过** → 反相关（部分）由生成设置驱动 → 降级为「under-powered / grid effect」，主张转向「换候选生成（设置匹配配对）」。
>
> 在该结果落地前，本文**一律**用「**at N=188 未检出单一生成设置的显著混淆，但 under-powered**」表述，**不写**「intrinsic / confound excluded / confirmed / resolved」。

复现命令见 §8。

## 7. 对实验 / 论文的影响（**据 §6 未关闭，作定向但不终局的重构**）

> §6 的 guidance-confound **未关闭**（偏相关待裁决），本节结论据此作**定向**重构，但**不**作终局断言；凡涉「intrinsic」均挂起待 `probe_analysis.py`。

**贡献定位（重定位 novelty，审稿 C6/A）**：从「一个能用的 DPO 配方」转为**机理性诊断研究**——但**不**说「首次发现 / 首次量化 / 中心发现」，而是：

> **(1)** 把一个**已知**的 likelihood-vs-quality / CFG off-manifold gap（Theis 2016 / Ho & Salimans 2022 / Gao 2023），在**连续-latent flow-matching TTS（dots.tts）**上做**领域量化**；**(2)** 给出据我们所知该架构的**首个 DPO 实例（DPO-FM）**；**(3)** open-SOAR。论点：**likelihood-based DPO 在 reward 偏好 off-manifold 时是错的工具**——这解释了它的不稳定，并**警示**不可照搬离散-token 的偏好配方。

> 📎 范围收窄（审稿 C3/F）：上述反相关机理可能是 **dots.tts 的 VAE/flow-head 几何所特有**。故标题/Abstract/§1/§8 的整类断言**收窄到 dots.tts**，并标注 **may be architecture-specific（待 VoxCPM 等二次复现）**；标题以 cautionary/diagnostic 为头，不再以 recipe 为头。

### 7.1 关键推论：哪些臂**绕开** L2 对齐失败

- **`open_soar`（reward-free，clean-vs-perturbed 轨迹）绕开**：偏好建立在「**轨迹洁净度**」（与 FM 似然**同向**，by construction）而非外部 reward 上，不依赖「best-vs-worst 偏好跟似然走」这一前提，**仍是候选臂**——L1 已由 §4.2 训练侧 by-construction 印证；其 held-out 增益须由 **Table 1（planned）** 证。
- **`sft`（仅在 winners 上做监督 FM）绕开**：它**不做 win/lose 的 `L_FM` 对比**，只把模型拉向 winner 音频 → **不踩 L2 这个坑**，可能是真正起作用的**建设性臂**——**`sft` 是决定性对照**，须各自报 held-out 增益 CI 排除 0（planned）。

### 7.2 构想的建设性方向（非 likelihood-DPO）

按新论点，正确的两类路是 **(a) 偏好与似然对齐**（open-SOAR），**或 (b) 非似然目标**：

- 在 winners 上做 **reward-weighted regression**；
- 经**可微 vocoder** 的直接 reward 反传；
- 用**学习式 value / preference 头**取代「`L_FM` 当 logprob」。

> 🔴 **n=3 冒烟边界（先读这条再看数）**：以下数字来自 **n=3** 的 eval 冒烟（`run_matrix --manifest eval_smoke(3句) --nfe 10 --skip-streaming`），**CI 巨大、数字噪声极大**，**仅用于确认评测管线端到端跑通 + 效应方向**，**绝不可读出精确量级、不可当定论、不可写进 PAPER 正文作结果**。本节的「DPO-FM 主动崩坏」「损害 ∝ pair 纯度」「sft/open_soar 改善」均为**待检验的预测（planned / we will test）**，精确量级与显著性以**全量 n=100** 为准（待回填）。

§3 的机理（**off-manifold 反相关，Spearman −0.187**）与 §4.2 的训练侧对照（`open_soar` by-construction 学满分、`dpo_multiobj` 学不动）已构成两级**线索**；本节是机理给出的**下游预测**，把 base + 4 臂真实合成后送评测以**验证方向**——而非已成事实的结果。

### 9.1 预承诺的可证伪规则（解盲前，审稿 DA）

- **预测**：reward-based `dpo_multiobj` 相对 `base` **主动退化**（非仅欠拟合 ≈ base），且退化幅度 **∝ pair 信号纯度**（越干净 / 越非平局，错向梯度越强 → 伤越重）。
- **证实判据**：全量 n=100 上 `dpo_multiobj` 的 hard-WER/UTMOS 相对 `base` 的 delta，bootstrap CI **排除 0 且为退化方向**。
- **证伪 / 撤回规则**：若 CI 与 `base` **重叠** → **撤回**「active degradation」表述，**且不得**改叫「under-fitting」充数；若 `sft`/`open_soar` 的 held-out 增益 CI **不排除 0** → 不得称其「escape / 建设性臂」。

### 9.2 管线已端到端跑通（这一条是**已成事实**）

`base + 4臂 合成（DotsTtsRuntime.generate）→ WER（Whisper-v3）/ SIM（ecapa）/ UTMOS（utmos22_strong）→ aggregate → main_table` 全链路在 GPU 机器上**端到端跑通**（n=3、nfe=10、skip-streaming 的冒烟配置）。**本节唯一已确证的是评测管线本身可用**；下面的读数仅锁方向。

### 9.4 机理闭环（**预测**：off-manifold → 训练侧 → 生成侧）

- **预测：DPO-FM 不是「学不动 ≈ base」，而是主动把模型搞坏**：n=3 上 `dpo_multiobj` WER 从 base **0.076 → 0.88**、SIM **0.85 → 0.38**、UTMOS **4.41 → 2.43**（方向，待 n=100 证）。机理：§3 的 off-manifold 反相关使隐式奖励梯度**指错方向**，600 步把策略一路推向退化。
- **训练侧早有预警**：`dpo_multiobj` 训练时 `fm_w` 从 base 的 **~0.5 涨到 ~1.0**（winner 的重建在**变差**）——生成侧崩坏在训练侧已留下指纹。
- **预测：损害 ∝ pair 信号纯度**（本节最强的方向性预测，待证）：
  - **`dpo_multiobj`** 的 pair 最干净（**0% 平局、reward 差最大**）→ 错向梯度**最强** → 疑似崩最惨（n=3 WER 0.88）；
  - **`dpo_weronly`** 的 pair **63% 平局** → 信号弱 → 疑似只**轻度退化**（n=3 WER 0.24）。
  - 「**越干净的偏好、错向时伤得越重**」——若 n=100 证实，则错向梯度强弱可由 pair 纯度**单调预测**，是「off-manifold 为因、非随机崩坏」的强证据。⚠️ 注：purity-scaling 须在**固定 reward 定义**下比较（cleanest-pairs vs near-tie pairs），而非用 multiobj-vs-weronly 的不同 reward 充当纯度差——否则与信号强度混淆（审稿 P2）。

### 9.5 对照预测：sft / open_soar 改善，不踩坑

- **`sft`**（仅 winners 监督 FM，**不做 win/lose `L_FM` 对比**）→ n=3 WER **0.076 → 0.039**、SIM **0.85 → 0.87**（UTMOS 4.41 → 4.09 略降）——与 §7.1 预测一致，**待 held-out CI 证**。
- **`open_soar`**（似然对齐：clean vs perturbed）→ n=3 UTMOS **4.49（五臂最佳）**，WER/SIM 与 base 持平——**待 held-out CI 证**。
- 二者都**绕开「win/lose 的 `L_FM` 反向对比」这个坑**——生成侧 n=3 **初步**印证机理推断（§7.1），但 escape 须 held-out 增益 CI 排除 0 方成立。

### 9.6 三级证据链（**当前为「线索」，第三级是预测**）

> **机理（§3，off-manifold 反相关 Spearman −0.187）→ 训练侧（§4.2，`open_soar` by-construction 学满分 / `dpo_multiobj` 学不动 + `fm_w` 0.5→1.0 预警）→ 生成侧（本节，n=3 方向：`dpo_multiobj` 疑似崩坏 / `sft`·`open_soar` 疑似改善）**。前两级为已观测线索，**第三级是 n=3 仅锁方向的预测**；三级是否自洽**待全量 n=100 解盲**。
